# 주제 등록부

> 대본·플러그인은 아래 JSON 블록만 읽는다(`3_시스템/roles.py topics` · `canon <별칭>` · `topic <경로>`). 옵시디언 홈 «관리 › 주제 등록부»에서 표로 고칠 수 있다.
> **정식 이름** = 주제 자리(`3_시스템/roles.json` `topic_roots`) 바로 아래 폴더 이름. **영역** = `배움`·`일`·`생활`·`분야`. 칸: `이름`·`영역`·`별칭`·`학기`(학교 과목)·`종류`(학교)·`상태`(진행·끝남)·`단추`(주제 패널 머리의 말).

```json
{"topics": [
  {"이름": "외부뇌", "영역": "일", "별칭": [], "상태": "진행"}
]}
```
