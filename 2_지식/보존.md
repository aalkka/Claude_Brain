# 보존 일정표

> 대본은 아래 JSON 블록만 읽는다(`3_시스템/roles.py retention`). 값을 고치면 다음 실행부터 따른다 · 옵시디언 홈 «관리 › 보존 일정표». `날: null` = 무기한(시스템이 지우자고 하지 않음).
