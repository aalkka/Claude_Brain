# 진행 중

> **정리 = 이중 주체**. Claude는 세션에서 종결을 확인한 항목을 스스로 지운다.
> 그걸 Claude가 못 알아채는 경우(이미 끝났거나·이제 안 할 일) 사용자가 `- [ ]` → `- [x]` 로 표시해두면 다음 세션에 하위 불릿까지 통째로 삭제된다.
> 원문은 링크된 노트와 git 이력에 남으므로 소실되지 않는다.
> **새 항목은 반드시 `- [ ]` 로 적는다** — 체크박스가 없으면 사용자가 체크할 수 없어 이 체계가 무너진다.
> **크기 상한 = 파일 ≤6KB · 항목 ≤2줄/300자** (이 파일은 매 세션 통째로 주입된다). 상세 이력은 프로젝트·세션노트에 두고 여기엔 **gist + 링크 + 다음 행동**만. 기존 항목에 이력 append 금지 — **교체**한다.
