# 자동 차단기가 폰 앱 자기 갱신을 조용히 막음

## 증상
- S25 에서 외부뇌 앱(brain-phone) 자기 갱신 성공 0회. 0.7.0(판 7)은 기록 없음 · 0.8.0(판 8)은 받음 3회 → 3회 모두 실패(11-14). 깔린 판은 손 설치 0.6.0 그대로였음.
- 폰 화면엔 아무것도 안 뜸(창·알림 없음). 실패는 PC 서버 로그에만: `3 INSTALL_FAILED_ABORTED: Self update is blocked by unknown source package 허용=켬`.
- 같은 코드가 순정 Android 16 에뮬레이터에선 화면 없이 깔림 → 폰 쪽 원인.

## 근본 원인 (잰 것 · 11-15 00:2x~00:4x)
- 삼성 자동 차단기. 같은 코드(0.8.0)를 번호만 바꿔 두 번 시험, 둘 다 앱 화면에서 «지금 받기»:
  - 판 9 · 자동 차단기 **끔** → 받음 00:29:18 → «됨 9판» 00:29:30 · «확인 필요» 0 = 누름 없이.
  - 판 10 · 자동 차단기 **켬** → 받음 00:37:57 → 같은 실패 · 화면 아무것도 안 뜸.
- 앱의 «출처를 알 수 없는 앱 설치» 권한은 켬(`canRequestPackageInstalls` = 참) — 안드로이드 권한이 아니라 삼성 층이 막음. 앞·뒤 화면과 무관.
- 이 폰의 자동 차단기는 30분만 꺼짐(사용자) → **사람 손 없는 자동 갱신은 불가**. 되는 최선 = 차단기 30분 끔 → «지금 받기».

## 시험할 때 걸린 것
- 잘 시간(23~08)엔 갱신 단계를 건너뜀 · 실패한 판은 6시간 다시 안 받음(폰 안 기록이라 서버에서 못 지움) → 판 번호를 올려(같은 코드) 피하고, 잘 시간을 [[알림-설정]] 에서 잠깐 늦춤(시험 뒤 되돌림).
- 저장소 작업 트리에 다른 세션 미커밋 고침이 있어 깨끗한 워크트리에서 빌드. `build.py` 는 키 파일이 없으면 **새 키를 만든다** → 워크트리에 `keys/debug.keystore` 를 먼저 복사(새 키 = 서명 불일치로 갱신 거부).

## 고침 (0.11.0 · 11-15 · `897abc0`)
- 실패하면 조용한 알림(차단기 문구면 «자동 차단기에 막힘 · 자동 차단기를 끄고 눌러서 설치») · 누름과 «지금 받기» = 6시간 대기·잘 시간 없이 바로 다시. 0.12.0 까지 폰에 깔림.
- 쓰는 법: 알림이 뜨면 → 자동 차단기 30분 끔 → 알림 누름(또는 «지금 받기»).

## 남은 것
- 막힘 알림 자체는 실제 폰에서 아직 안 잼(판 12 때 차단기가 꺼져 있었음) → 다음 출시를 차단기 켠 채 받을 때 잰다.
- 판 12 설치 때 Play 프로텍트 «앱 스캔» 창이 처음 뜸(판 9·11 은 안 뜸 · 까닭 모름). 개인 APK 엔 서버 열쇠가 들어 있어 «앱 스캔·앱 보내기»는 누르지 않는 것이 맞음 — 11-15 한 번 보냄 · 서버가 tailnet only 라 열쇠는 안 바꿈.
