# 같은 주소 두 번 등록 → 플러그인 못 켬

## 증상
- 에뮬레이터(옵시디언 1.15.0): brain-server 갱신기가 brain-calendar 를 깔고 켰는데, 판 파일(core)이 없음. 로더 Notice «외부뇌 못 켬» · `state.failed` 는 비워져 있음(로더가 다 버린 뒤 비움).

## 근본 원인
- 콘솔: `Error: Action "brain-calendar" is already registered as a handler.` — `registerObsidianProtocolHandler` 가 이미 쥔 주소에 대해 **던진다**(옛 판처럼 덮어쓰지 않음).
- brain-server 0.6.4 는 캘린더가 없는 볼트에서 같은 주소를 받는다. 같은 세션에 캘린더를 깔면 캘린더 onload 가 등록하다 던져 켜지기 실패.

## 해결
- brain-server: 주소를 `workspace.registerObsidianProtocolHandler(주소, 처리기)` 로 직접 쥐고, 캘린더를 깔기 직전 `unregisterObsidianProtocolHandler(주소, 처리기)` 로 놓는다(이 처리기만 풀림). 못 켰으면 다시 쥔다.
- brain-calendar: 등록을 try/catch — 주소를 못 받아도 캘린더는 켜진다.

## 재발 방지
- 두 플러그인이 같은 주소를 받으려면 «한쪽만 등록 + 넘길 때 풀기». «늘 둘 다 등록»은 1.15 에서 깨진다.
- 로더로 켜는 판 파일은 onload 오류가 «못 켬» 하나로만 보인다 → `console.error` 를 잡고 껐다 켜서 원인을 본다(진단 방법).
