# 쓰기 위치
**작업 중인 것 → `0_작업/<주제>/`**(2026-10-18 신설). 빌드 중인 docx·초안·보고서 재료(캡처·코드·사진·영상)를 둔다. 넣고 지우기 자유 · 끝나면 **승격**(제출본 PDF → `1_수집/<분류>/제출/`, 지식 → `2_지식/notes/`)하거나 삭제해 폴더에서 사라진다. md 아닌 파일은 git 제외. 1_수집 의 «원본 불변»은 여기 적용되지 않는다. 옵시디언에서 보이므로 Brain Source 플러그인으로 docx 를 읽고 고칠 수 있다.
지식→2_지식/notes/ · 세션→sessions/ · 결정→decisions/ · **모듈 산출물→2_지식/modules/<모듈명>/** · 진단(외부뇌 시스템)→3_시스템/_ref/
프로젝트 문서·진단은 프로젝트 폴더로(예 2_지식/notes/<프로젝트>/ , incident은 2_지식/notes/<프로젝트>/_ref/). 3_시스템/_ref/ = 외부뇌 시스템 자체 전용(훅·검색·규약·인덱스). 프로젝트 버그 혼입 금지.
**modules/ = 모듈(플러그인)이 생산한 지식노트 전용**(2026-07-27 신설). 모듈 *설계노트*는 여기가 아니라 notes/(`외부뇌-<모듈명>-모듈.md`). 파생·캐시는 3_시스템/_index/<모듈명>/.

# 링크 입도 — 노트냐 문단이냐 (2026-07-28 신설)
기본은 `[[노트명]]`(노트 전체). **긴 원문의 특정 대목을 가리킬 땐 문단 단위로 내린다**:
- 섹션 → `[[노트명#헤딩]]` · 문단·표·목록 → `[[노트명#^blockid]]`
- 블록 id는 대상 블록 **끝줄 뒤에 빈 줄 없이** `^blockid` 한 줄(영숫자·하이픈만).
**근거**: §2 "요약은 원문을 대체하지 않는다(포인터+gist)"의 실행 수단. 노트 전체만 가리키면 읽는 쪽이 다시 통독해야 해 §2 "통독 금지"와 충돌한다. 제작 볼트 2026-07-28 실측 = 블록참조 **0건**·헤딩링크 21건 → 입도가 노트에 묶여 있었다.
**주의**: 프론트매터 `links:`에는 따옴표 배열 그대로 — `links: ["[[노트#^id]]"]`.

# 종결 기록은 문서 최상단 (2026-08-17 신설)
논점이 종결되면 **제목 바로 아래**에 `> [!done] 종결 — <결론> (<날짜>)` 배너로 남긴다. 결론·근거 링크·"다시 열지 않는다"를 한 덩어리로.
본문의 옛 서술은 지우지 않고 `(→ 최상단 종결 배너 참조. 이 서술은 <날짜> 시점이다)`만 덧붙인다 — 판단 이력이 근거다.
**해당 문단 밑에 달지 않는다.** 그러면 그 문단까지 읽어야 보이고, 문서를 부분 인용·검색으로 읽는 경우 옛 서술이 그대로 현재 판단으로 오독된다.
**근거**(제작 볼트 실측): 종결된 논점이 종결 당일 다시 문제로 제기됐다 — 통산 6회. 원인은 문서 중간에 남은 **옛 시점 서술**을 현재 판단으로 읽은 것이었고, 문단 밑 주석으로는 막히지 않았다.

# 파일명·폴더 규약 (Stop 훅이 강제)
- **파일명(basename) 볼트 전역 고유** — 위키링크 `[[name]]`가 basename 해석이라 동명 노트는 모호. 스코프 2_지식/**·3_시스템/_ref/**서 중복 시 턴 종료 차단.
- **notes/·decisions/ 는 재귀 MOC 강제** — 정리용 하위폴더(예 notes/<프로젝트>/) 안 노트도 MOC 등재+프론트매터 필수. 단 **`_`접두 하위폴더**(예 _ref)는 비대상(프로젝트 incident 등).
- **modules/ 는 프론트매터만 강제, MOC 등재 면제** — 모듈은 MOC에 *설계노트 1줄*로 대표된다. 산출물마다 등재하면 MOC가 폭증(도그푸드 실측). 검색·중복basename·수식검사는 동일 적용.
- 정리용 그룹 폴더는 notes/ 안에 두면 됨(밖으로 빼면 검색·강제서 이탈). 핵심파일(MOC·recent·open-loops·설계노트·사용자설명서) 이동 금지.

# _index 배치 규약 (파생물 전용, gitignore)
**신규 파생물만 대상** — 기존 경로(`embeddings.json`·`hooks.log`·`pdf-cache/`)는 이동하지 않는다(경로가 search.py에 각인됨).
- `_index/cache/` — 재생성 무료·결정적. 언제든 삭제 가능.
- `_index/work/` — 재생성 유료·비결정적(전사·OCR·LLM 산출). 중간산출이며 최종물은 2_지식으로 승격. 승격 후 삭제 가능.
- `_index/<모듈명>/` — 모듈 파생(module-forge가 강제, 기존 유지).
- 로그는 `_index/*.log`. 무한 append — weekly-review 용량 보고 대상.

원본 보관: 재생성에 외부파일이 필요해도 **원본 경로를 기록하지 않는다**(사용자가 파일을 옮기거나 지우면 stale 경로가 혼란을 키움). 필요하면 사용자에게 파일을 다시 요청한다. (볼트 밖 파일 얘기다. 볼트 안 원본은 아래 §원본·색인.)

# 원본·색인 (2026-10-14 신설)
원본 형식 파일(pdf·docx·pptx·xlsx·hwp·html·영상 등)이 볼트의 정보원이다. 정리노트는 원본의 열화판이라 만들지 않아도 된다 — 대신 원본마다 **색인**을 붙여 링크·속성·검색되는 본문을 준다. 색인은 `3_시스템/ingest.py` 가 만들고, 들이는 절차는 `pdf-ingest` 스킬이다.
- **원본** = `1_수집/<분류>/<파일>` — 내용 불변. 분류 이동은 Claude(과목이 파일명·내용에서 분명할 때만, 애매하면 `_inbox` 잔류 + 질문). **복사 금지**. 같은 sha256 이 이미 있으면 들이지 않고 보고.
- **색인** = `1_수집/_색인/<원본 상대경로>.색인.md` — `3_시스템/ingest.py` 가 만들고 갱신한다. 사람이 고치지 않는다(다시 만들 때 사라짐). git 제외(원본에서 재생성). 같은 sha256 은 색인 하나(`also:` 에 다른 경로).
  - 3_시스템에 두지 않는 이유: `app.json` userIgnoreFilters 가 `3_시스템/` 이라 옵시디언 검색·그래프·백링크에서 빠진다.
  - 프론트매터: `type: semantic` · `source: user` · `format` · `origin`(볼트 상대경로) · `also` · `sha256` · `extractor` · `quality` · `confidence: hypothesized` · `tags: [색인]`.
  - 본문: 위치 단위 헤딩(PDF 쪽 · 슬라이드 · 시트 · 시각)마다 원본 링크 `[[<origin>#page=N|p.N]]`. 소화본은 **찾기 위한 색인**이다 — 문장 품질보다 위치 정확도가 중요.
  - 볼트 안 원본은 경로 + sha256 을 기록하고, 옮겨지면 ingest.py 가 해시로 다시 잇는다. 원본이 없어진 색인은 보고(고아).
- **메모** = 원본 옆 `<원본 basename>.md` — 사람 전용. Claude 는 요청 시에만 쓴다. 스크립트는 절대 쓰지 않는다. 같은 basename 의 원본이 둘이면 `<basename> (<확장자>).md`.
- **제출본** = 제출 확정 때 `1_수집/<분류>/제출/` 로 **PDF 만** 복사(최종 제출물 한 벌). 작업 파일(docx)과 재료(사진·csv·측정·코드·영상)는 `0_작업/<주제>/` 에 둔다.
- **git** = 1_수집 원본(비 md)은 올리지 않는다(원본 백업은 사용자 몫) · md(메모·아이디어)만 추적 · `_색인` 제외 · 영상·무손실 오디오는 볼트 전역 제외.
