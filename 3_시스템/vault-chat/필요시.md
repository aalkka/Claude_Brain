# 볼트 지도
- `0_작업/<영역>/<주제>/`: 진행 중인 작업
- `1_수집/`: 받은 원본(학교 자료 `배움/<과목>/`) · `_색인/`: 원본 찾기용 색인. 원본을 찾을 땐 색인을 Grep 하고, 색인의 `p.N` 링크로 쪽을 찾는다.
- `2_지식/<영역>/<주제>/`: 지식 노트(영역 = 배움·일·생활·분야) · `기록/`: 세션 기록 · `일/외부뇌/결정/`: 결정(ADR)
- `2_지식/MOC.md`: 영역 `##`·주제 `###` 아래 노트 한 줄 목록. 주제의 노트를 찾으려면 `### 주제` 를 Grep 한다.
- `2_지식/주제.md`: 주제와 별칭 · `2_지식/일정/`: 일정 · `2_지식/open-loops.md`: 진행 중인 일 · `2_지식/recent.md`: 최근 세션

# 사용자
학교·전공 같은 사실은 `2_지식/profile.md` 를 읽는다(기억은 `3_시스템/_claude-memory/`).

# 사용법
기능·사용법을 물으면 `3_시스템/tutorial/찾아보기.md` 를 읽고, 자세한 것은 `3_시스템/설명서/` 의 그 장을 읽고 답한다. 켜진 모듈의 장은 `3_시스템/설명서/_index/` 에 있다(거기 없으면 꺼졌거나 없는 모듈이다). 튜토리얼 대본은 같은 폴더의 `<장>-<이름>.md` 이고, 모듈 장은 앞머리에 적힌 폴더에 있다. 메시지 앞머리에 `[튜토리얼 …]` 이 오면 사용자가 그 단계를 하는 중이다.

# 찾는 순서
1. 고른 글·보는 파일 주변
2. 주제 폴더와 `MOC.md`의 그 주제 칸
3. 볼트 전체 Grep — 표현이 다르면 놓칠 수 있으니 못 찾았을 때는 «Grep 으로 못 찾음»이라고 말한다.
