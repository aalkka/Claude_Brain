# 자격 카드

> 공지 필터(`3_시스템/notice-filter.py`)가 «나에게 해당하나»를 따질 때 읽는 내 값이다. 만들기 = `py -3 .claude/skills/collect_desk/scripts/collect_desk.py new card`(이 빈 틀을 노트 자리에 옮김 · 있으면 안 덮음).
> 모르는 칸은 `null` 로 둔다 — 그 조건은 «모름»이 되어 빼지 않고 «확인 필요»로 남는다(놓침이 헛것보다 비싸다). `[]`(빈 목록)는 «없음»이라는 뜻이라 빼는 근거가 된다.
> 이 노트는 민감 정보다(`sensitive: true` · push 제외). Claude 는 값을 대화·배포판에 옮기지 않는다.

칸 뜻(줄여서): 신분 = «학부 재학» 같은 글(학부·대학원·재학·휴학·신입생·졸업예정 중 낱말) · 전공분야 = 내 분야 낱말 목록(예: ["이공", "자연과학", "이학", "이과", "물리", "기초과학", "과학기술", "STEM", "자연계"] · 낱말은 3_시스템/notice-filter.py FIELD_WORDS 에서) · 학년 = 정수 · 학기 = «2학년 1학기» · 직전학기 = {"평점": 3.5} · 소득구간 = «8구간» · 지역 = {"본인": "", "부모": "", "출신고교": ""} · 특수 = 해당 집단 목록(없으면 `[]`) · 학사 = {"다중전공": "없음"} 처럼 할일 대상 · 관심 = 늘 남길 말 · 제목규칙 = [{"이름", "말": [...], "조건"}] · 황금 = 현금 판정 칸(비우면 기본).
