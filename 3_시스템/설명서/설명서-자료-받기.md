# 자료 받기

목차 = [[사용자설명서]]

## 받은함

자료가 처음 들어오는 정거장이다(`1_수집/받은함`). 복사가 아니라 옮기기라 원래 자리에 사본이 남지 않는다.

**넣는 길 셋**

| 길 | 어떻게 | 언제 |
|---|---|---|
| 우클릭 | 윈도 탐색기에서 파일 우클릭 › «외부뇌 받은함으로» | 탐색기에서 고를 때 |
| 단축키 | `Ctrl+Alt+B` — 탐색기에서 고른 파일 · 탐색기 밖이면 내려받기의 방금 받은 파일(30분 안) | 크롬에서 받은 직후 |
| 끌기 | 윈도 탐색기 왼쪽 «받은함» 즐겨찾기로 끌어 놓기 | 탐색기 안에서 |

옮기면 화면 오른쪽 아래(알림 센터 `Win+N`)에 윈도 알림이 뜬다. 파일 이름 · 간 자리 · **«되돌리기»** 단추가 있다. 누르면 원래 자리로 돌아간다(하루 안).

**옵시디언이 꺼져 있으면** 받은함에서 기다렸다가 켤 때 정리한다(12초쯤 뒤). 옵시디언이 저절로 켜지지는 않는다.

## 받은함 정리

옵시디언이 켜져 있으면 넣자마자 판단한다.

| 판단 | 무엇이 | 어떻게 |
|---|---|---|
| 제자리로 | 이름에 주제(별칭 포함)와 칸 낱말이 있는 문서 | `1_수집/<영역>/<주제>/<칸>/` + 색인 |
| 휴지통 | 같은 내용이 이미 있는 파일 · 끝난 작업의 재료 | 30일 보관 |
| 치움 | 빈 폴더 | |
| 작업 자리로 | 사진·측정·코드 같은 재료 | `0_작업/…` — 원본 층에 안 들인다 |
| 남김 | 주제를 못 찾았거나 칸을 못 정한 것 · md 메모 | 홈 «받은함»에서 사람이 고른다 |

**칸을 정하는 낱말**: 제출(최종본) · 족보(기출) · 시험(중간·기말·퀴즈) · 과제(숙제·보고서·report·hw) · 공지(안내) · 강의자료(강의·주차·제N강·N강·lecture·slide·chapter·week). 앞에서부터 먼저 맞는 것을 쓴다.

**안 옮겨졌을 때**: 홈 «받은함» 줄 오른쪽에 제안이 보인다. 마우스를 올려 옮기기를 누르거나 Claude 에게 말한다. 파일 이름에 주제·칸 낱말을 넣으면 다음부터 저절로 간다. 별칭은 주제 등록부에서 더한다.

## 볼트 밖

내려받기·바탕화면의 볼트에 없는 문서를 홈 «볼트 밖»에 보여 준다. 옮기지는 않는다. 줄에 마우스를 올려 «받은함으로» 또는 «숨김».

## 따라가기

옵시디언 밖(윈도 탐색기 등)에서 볼트 안 파일을 옮기거나 지워도 시스템이 따라간다.

- 옮김: 몇 초 뒤 알림 «바깥에서 옮김 N» · 색인·링크·장부를 맞춘다.
- 지움: 장부에 적는다. LMS 원본이면 홈 «사라짐»에서 «되받기»(다음 수집 때) 또는 «그대로».
- 한꺼번에 많이 사라지면 멈추고 홈에서 묻는다.

## 원본 색인

원본 옆에 찾기용 색인을 만든다(`1_수집/_색인/…색인.md`). PDF 는 쪽 번호가 붙어 검색 결과에서 그 쪽으로 바로 간다.

- **저절로**: 받은함 정리 · LMS 수집 뒤
- **직접**: 홈 행위 «원본 색인» · 명령 «색인 지금 만들기(바뀐 원본 전부)» · 파일 우클릭 «외부뇌 · 원본 색인 다시»
- **말로**: «이 PDF 넣어줘»
- **그림·스캔**: 색인 노트 탭 머리의 «그림 읽기» 단추로 그림·손글씨를 읽는다(Claude 사용량이 들어 누를 때만 돈다).

## LMS 수집

학교 LMS 의 공지·과제·강의자료·내 제출을 원본 그대로 받는다. 크롬 확장 «외부뇌 LMS 수집»이 필요하고 로그인은 사람이 한다.

- **실행**: 홈 행위 «LMS 수집» · 홈 «수집»에 마지막 시각.
- **어디로**: `1_수집/배움/<과목>/<칸>/` · 마감은 일정으로 · 내 제출은 `제출/`.
- **안 될 때**: 크롬에 로그인했는지 · `chrome://extensions` › 확장 새로고침.
- **보기·끄기·고치기**: 왼쪽 리본 «수집» → [[설명서-수집|수집 창]].

배포판에는 들어 있지 않은 모듈이다.

## 웹 공지

학교 게시판의 장학·학사 공지를 모은다. 홈 행위 «웹 공지 수집». 공지는 마감 + 30일 뒤 저절로 휴지통으로 간다(보존 일정표). 출처마다 보고 끄고 고치는 곳은 [[설명서-수집|수집 창]]이다.

## 웹페이지

대화창에 주소를 주고 «읽어줘» · «저장해줘»(일 모드).
