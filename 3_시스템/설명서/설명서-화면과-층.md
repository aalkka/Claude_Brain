# 화면과 층

목차 = [[사용자설명서]]

## 켤 때

볼트를 다시 켜면 가운데에 홈 하나만 뜨고 좌우 곁창은 접혀 있다.

- **이전 창 되살리기**: 오른쪽 위 알림 «이전 창 N개를 복구하시겠습니까?»의 «복구». 탭·나눈 칸·새 창·보던 탭과 끌 때 펴져 있던 곁창이 돌아온다. 켠 뒤에 연 탭은 그대로 남는다.
- **대화창의 대화도 함께**: 끌 때 대화창에 열려 있던 대화가 돌아온다(N 에 1 로 센다 · 창 없이 대화만 있었어도 묻는다). 되살리는 데 토큰이 들지 않고, 이어서 보내면 앞 대화를 알고 답한다. 턴 끝 줄(시간·토큰)·바뀐 파일 카드와 되돌리기·승인 카드·입력 상자에 쓰던 글은 돌아오지 않는다. 다른 대화가 열려 있으면 «바꾸기»로 묻는다. 대화창을 닫고 껐거나 «새 대화»로 비우고 껐으면 되살리지 않는다.
- **알림을 닫았으면**: 명령 «외부뇌 이전 창 복구»(`Ctrl+P`).
- **이렇게 시작하기 싫으면**: 설정 › Brain Base › 켤 때 › «홈만» 끄기.
- 명령 «저장하지 않고 앱 다시 불러오기»도 켠 것으로 친다.

## 새 판이 설치될 때

brain-base 새 판이 폴더에 다 들어오면 옵시디언을 다시 켜지 않아도 스스로 다시 읽는다(0.36 이상이 떠 있을 때 · brain-base 만 · 캘린더·brain-source 는 다시 켜기).

- **보이는 것**: 오른쪽 위 알림 «다시 읽는 중». 그동안 클릭·글자·단축키가 막힌다. 시험 볼트에서는 1초 안쪽이었다. 끝나면 «다시 읽음 · 판».
- **미루는 때**: 답하는 중 · 입력 상자에 쓰던 글이나 붙인 것 · 상자 고르기 · 튜토리얼 · 열린 창(설정 포함) · 노트 저장 실패. 알림으로 까닭을 알리고, 끝나면 다시 읽는다.
- **대화**: 끊기지만 곧바로 복구 길로 돌아온다. 사라지는 것 = 턴 끝 줄 · 바뀐 파일 카드와 되돌리기. 답이 끝나자마자 돌 수 있어 방금 턴의 되돌리기도 잃을 수 있다.
- **잠긴 채 남지 않는다**: 15초가 지나면 저절로 풀린다. «새 판을 못 켰습니다»·«다시 읽지 못했습니다»·«늦습니다»가 뜨면 옵시디언을 다시 켠다.
- **자동으로 안 도는 때**: 이미 읽은 판으로 되돌림 · 0.35 이하 옛 빌드 · 세 파일이 빌드 표시와 안 맞음(배포판을 거치며 줄바꿈이 바뀐 경우 등). 이때는 다시 켠다.
- **옵시디언 내부에 기댄다**: 플러그인 내리기·올리기와 설정 창 판정은 공개 API 가 아니다. 옵시디언 판이 바뀌면 안 돌 수 있다.
- **아직 안 잰 것**: 실제 볼트 크기 · 진짜 키보드·한글 입력 · 새 창에 진짜 입력 · 설정이 뒤쪽 창일 때. 시험 볼트에서만 쟀다. 결과 기록 = `3_시스템/_index/reload-last.json`.

## 홈

오늘 볼 것을 한 장에 모은 화면이다. 왼쪽 리본의 집 그림 · 명령 «외부뇌 홈 열기».

| 묶음 | 보이는 것 | 누르면 |
|---|---|---|
| 받은함 | 들어온 파일과 정리 제안 | 파일 열기 · 마우스를 올리면 옮기기·휴지통 |
| 볼트 밖 | 내려받기·바탕화면의 볼트에 없는 문서 | 받은함으로 · 숨김 |
| 사라짐 | 바깥에서 지운 LMS 원본 · 행방 모르는 파일(있을 때만) | 되받기 · 그대로 |
| 작업 | 작업 폴더에 있는 작업 | 체크 = 한 번 더 묻고 끝냄 · 줄 = 탐색기에서 보기 |
| 마감 | 가까운 마감 | 주제 패널 |
| 수집 | LMS·웹 공지 마지막 수집 | |
| 휴지통 · 장부 | 지운 것 · 최근 옮김 | 되살리기 · 되돌리기 창 |
| 주제 | 최근 바뀐 주제 다섯 · «더 보기» | 주제 패널 · 마우스를 올리면 Claude |
| 기록 | 진행 중 · 최근 세션 · 프로필 | 읽기 창 |
| 관리 | 켜진 모듈의 화면 · 튜토리얼 · 설명서 · 주제 등록부 · 보존 일정표 · 장부 | 표로 고치는 창 |
| 행위 | LMS 수집(LMS 모듈이 있을 때) · 일정 다시 · 받은함 정리 · 주간 점검 · 행위 고르기 | 그 일을 실행 |
| 모듈 | 기능 묶음과 상시 토큰 | 스위치로 켜기·끄기(바로 반영 → [[설명서-설정과-표]]) |

오른쪽 위 ✓·△·✗ = 건강(누르면 자세히) · 도는 단추 = 다시 읽기.

## 탐색기

왼쪽 곁창. 옵시디언 기본 탐색기를 대신한다(설정 «기본 탐색기 대신 쓰기»).

- **파일 탭**: 폴더 나무. 위에 새 노트 · 새 폴더 · 정렬 · 모두 접기.
- **주제 탭**: 고른 주제의 작업·원본·노트·기록. 머리 이름을 눌러 주제를 바꾼다. «모든 주제» = 영역 → 주제 · 보류·끝남 묶음.
- **누르면 새 탭**: 이미 열린 파일은 그 탭으로 간다. `Ctrl` + 클릭 = 지금 탭(설정 «누르면 새 탭»).
- **이름 바꾸기**: `F2` · **옮기기**: 끌어 놓기 · 링크가 따라오고 장부에 남는다.
- **우클릭**: 이름 바꾸기 · 휴지통으로 · 이 주제로 Claude · 주제 패널 · 작업 폴더 만들기 · 주제 붙이기 · 끝냄(작업일 때) · 폴더의 «새 노트»에 마우스를 대면 Word·Excel·PowerPoint.
- **점**: 끝난 작업 표시. 마우스를 올리면 이름이 보인다.
- 숨긴 것: `3_시스템` · 색인 · 뿌리의 `CLAUDE.md`·`README.md` · 지식 층 바로 아래 낱파일(홈 «기록»·«관리» · `Ctrl+O` 로 연다).

## 기다릴 때

오래 걸리는 일에는 도는 고리와 낱말이 뜨고, 3초부터 경과 초가 붙는다. 숫자가 멈추면 앱이 멈춘 것이고, 늘어나면 앱은 살아 있고 기다리는 중이다.

## 네 층

| 층 | 무엇 | 규칙 |
|---|---|---|
| `0_작업/<영역>/<주제>/` | 진행 중인 일 | 끝나면 비운다 |
| `1_수집/<영역>/<주제>/` | 받은 원본 | 내용을 시스템이 고치지 않는다 · 옮기고 지우기는 자유 |
| `1_수집/_색인/` | 원본을 찾기 위한 색인 | 기계가 만든다 |
| `2_지식/<영역>/<주제>/` | 노트 | 영역 = 배움·일·생활·분야 |
| `2_지식/기록/` | 세션 기록 | |
| `3_시스템/` | 대본·설정·이 설명서 | 탐색기에 안 보인다 |

한 주제의 자리는 층마다 같은 이름이다. 주제 탭이 이것을 한 곳에 모아 보여 준다.
