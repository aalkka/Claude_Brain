# 공부와 과제

목차 = [[사용자설명서]]

문제 풀이·채점·모의고사 같은 공부 도구는 모듈이다. 켜져 있으면 [[사용자설명서]] «모듈» 칸에 장이 있다.

## 보고서

1. 주제에서 «작업 폴더 만들기»(탐색기 우클릭) 또는 Claude 에게 맡긴다 — `0_작업/배움/<과목>/<과제>/`.
2. 받은 재료(사진·측정·코드)는 이름에 과목을 넣어 받은함으로 보내면 작업 자리로 간다.
3. 보고서를 만든다. docx 는 옵시디언에서 바로 열어 고친다 → [[설명서-원본-보기와-고치기]].
4. 제출 전 «표 안 나눔» · PDF 만들기.
5. LMS 에 제출하면 다음 수집 때 제출본이 `제출/` 로 들어오고, 작업 폴더는 볼트를 켤 때 저절로 비워진다. 바로 비우려면 홈 «작업»에서 체크.

사진·영상에 없는 결과는 쓰지 않는다. 문체·양식 지시는 Claude 의 기억에 쌓인다.

## 노트 정리

- «이거 노트로 정리해줘»(일 모드): 지식 층에 노트 + MOC 한 줄.
- 요약은 원문을 대신하지 않는다. 노트에는 원본 링크가 남는다.
- 카드로 펼쳐 보기: «캔버스 만들어줘».
