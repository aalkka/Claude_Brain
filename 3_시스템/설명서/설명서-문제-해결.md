# 문제 해결

목차 = [[사용자설명서]]

## 먼저 볼 것

- **건강**: 오른쪽 아래 상태 막대 ✓ △ ✗ · 명령 «외부뇌 건강 보기» · `py -3 3_시스템/brain.py doctor`. △·✗ 줄이 무엇이 문제인지 말해 준다.
- **전에 비슷한 일**: «예전에 비슷한 문제 어떻게 풀었지?» — `3_시스템/_ref/` 를 찾는다.
- **멈춘 건지 모르겠다**: 대기 표시의 초가 늘어나면 일하는 중이다. 초가 멈춰 있으면 옵시디언이 멈춘 것이니 다시 시작한다(아래).

## 증상별

| 증상 | 까닭 | 할 일 |
|---|---|---|
| 받은함에 넣은 게 안 옮겨짐 | 주제·칸 낱말이 없어 확신이 낮음 | 홈 «받은함»에서 옮기기 · 별칭 더하기 |
| 우클릭에 메뉴가 없음 | 받는 문이 등록 안 됨(배포판에는 받는 문 실행 파일(`3_시스템/door-app`)이 아직 없다) · 탐색기가 옛 메뉴를 쥐고 있음 · 볼트 안 파일에는 안 보임 | 행위 «받는 문 상태» · 탐색기 다시 시작 · `Shift`+우클릭 · 받는 문이 없으면 받은함 폴더로 끌기 |
| 윈도 알림이 안 뜸 | 방해 금지 · 알림 끔 | 윈도 설정 › 알림 › «외부뇌» |
| 찾기가 이상함 | 색인이 낡음 | 홈 행위 «찾기 색인» |
| 원본이 검색에 안 나옴 | 색인 없음 | 행위 «원본 색인» |
| 홈에 «brain.py 가 없음» | 볼트에 시스템 파일이 없음 | 설치 확인 · README |
| «파이썬을 못 띄움» | 파이썬 경로 | 설정 › 파이썬 |
| «claude 를 못 찾음» | Claude Code 경로 | 설정 › claude 경로 · `claude --version` |
| 대화창이 응답 없음 | 사용 한도 · 로그인 만료 | 계기의 사용량 · 터미널 `claude` › `/login` |
| 자동 판정 무응답(`no verdict`) | 판정 서버 지연 | 잠시 뒤 다시 |
| 탭이 다 사라짐 | 켤 때 창 비우기 | 알림 «복구» · 명령 «외부뇌 이전 창 복구» |
| 잠깐 조작이 안 됨 · 알림 «다시 읽는 중» | 새 판을 스스로 다시 읽는 중 | 15초 안에 저절로 풀림 · 안 풀리거나 «못 켰습니다»면 옵시디언 다시 켜기 |
| 곁창이 없음 | 켤 때 접음 | 왼쪽·오른쪽 위 곁창 단추 |
| 탐색기가 비어 있음 | 안 보이던 탭이 아직 안 그려짐 | 다른 탭을 눌렀다 돌아오기 |
| 옮긴 파일이 «행방 모름» | 볼트 밖으로 옮겼거나 이름이 크게 바뀜 | 홈 «사라짐»에서 «그대로» |
| 승인 창이 안 뜸 | 게이트 오류 | [[설명서-되돌리기와-안전]] «코어 승인» |
| 플러그인이 옛 판 | 옵시디언을 안 껐음 | 작업 표시줄까지 닫고 다시 열기 |
| PDF 쪽이 흰색 | 그리는 중 · 옵시디언 결함 | 다른 탭 갔다 오기 |
| docx 저장 실패 | Word 가 쥐고 있음 | Word 닫기 |
| 일하는 중에 창이 앞으로 튀어나옴 | 시험·대본이 창을 띄움 · 시험은 화면 밖에서 돌게 되어 있음(ADR-044) | Claude 에게 «창 기록기 켜 줘» · `py -3 3_시스템/winwatch.py watch` 뒤 `report` 로 어느 프로그램인지 확인 |
| 커밋이 `session:` 뿐 | 정상 | 자동 커밋이다 · 근거는 세션 노트 |

## 다시 시작

- **가벼움**: 명령 «저장하지 않고 앱 다시 불러오기»(켤 때 창 비우기가 돈다).
- **완전히**: 옵시디언을 닫고 작업 표시줄 아이콘이 사라진 뒤 다시 연다. 플러그인을 새로 깔았을 때는 이것이 필요하다.
- **탐색기**: 작업 관리자 › Windows 탐색기 › 다시 시작. 우클릭 메뉴 그림·글자를 바꾼 뒤.
