# 문제 해결

목차 = [[사용자설명서]]

## 먼저 볼 것

- **건강**: 오른쪽 아래 상태 막대 ✓ △ ✗ · 명령 «외부뇌 건강 보기» · `py -3 3_시스템/brain.py doctor`. △·✗ 줄이 무엇이 문제인지 말해 준다. 건강 창 제목 옆 렌치(«고치기» · 문제가 있을 때만)를 누르면 대화창 지금 대화 끝에 고르기 카드가 뜬다. 고칠 줄을 누르거나 «전체»를 누른 뒤 «고치기»를 누르면 새 대화(작업 모드)에서 Claude 가 고친다. «고치기» 없이 닫으면(× · Esc) 하던 대화는 그대로다. 새 Claude 세션은 시작할 때 문제 줄 이름을 이미 안다.
- **전에 비슷한 일**: «예전에 비슷한 문제 어떻게 풀었지?» — `3_시스템/_ref/` 를 찾는다.
- **멈춘 건지 모르겠다**: 대기 표시의 초가 늘어나면 일하는 중이다. 초가 멈춰 있으면 옵시디언이 멈춘 것이니 다시 시작한다(아래).

## 되찾기 — 남은 프로세스

볼트 일은 Claude 세션을 많이 띄우고, 세션은 배경 작업·에뮬레이터·시험 창을 띄운다. 띄운 세션이 잊으면 남아 메모리와 CPU 를 쥔다. **되찾기**는 프로세스마다 주인(띄운 Claude 세션)을 찾아, 주인이 끝났거나 오래 쉬는 것만 끈다.

- **켜기**: 바깥 설정 «되찾기 예약»(작업 스케줄러 «외부뇌 되찾기» · 10분마다 · 창 없음). Claude 에게 «되찾기 예약 켜 줘» — 자동 모드에서 막히면 `py -3 3_시스템/own.py install` 을 직접 친다.
- **무엇을 끄나** — 규칙마다 따로 켜고 끈다(설정 › 기능 단계 · 기본 = 다 켬 · 끈 규칙은 건강 줄에만 보인다):
  - «주인 끝난 프로세스 끄기» — 장부에 적고 띄운 것(`own.py run`)이 띄운 세션이 끝나거나 수명이 넘으면 자식째.
  - «시험 프로세스 끄기» — 격리 옵시디언·머리 없는 크롬·시험 AVD 로 적은 에뮬레이터(`py -3 3_시스템/own.py local --avd 이름` · 적지 않으면 에뮬레이터는 안 셈)를 띄운 세션이 없거나 2시간 넘게 쉬면. 시험 잠금이 있으면 안 끈다.
  - «배경 작업 과다 끄기» — 세션이 6시간 넘게 일 없는데 그 밑 배경 작업이 CPU 를 계속 먹으면.
  - «쉬는 세션 닫기» — 72시간 넘게 쉰 Claude 세션(닫기 전에 폰 알림 «닫음» · 모바일 연결이 있을 때 · 다시 열면 이어진다).
  - «메모리 압박 때 앞당기기» — 남은 램이 1.5GB 아래면 시험 프로세스·배경 작업의 쉼 문턱을 30분으로.
- **안 끄는 것**: 사용자가 연 옵시디언·크롬·터미널 · 상주 서버·예약 작업 · 볼트 밖 프로그램.
- **보기**: 홈 행위 «볼트가 띄운 프로세스»(`own.py list`) · 건강 줄 «되찾기 N분 전» · «쉬는 세션». 끈 것은 `3_시스템/_index/own/reclaim.jsonl`.
- **오래 걸리는 계산**(몇 시간짜리 변환·학습)은 Claude 가 `py -3 3_시스템/own.py run --keep --ttl 12h -- <명령>` 으로 띄운다 — 장부에 든 것은 «쉬는 세션 밑 배경 작업»으로 꺼지지 않고, 수명이 넘거나 세션이 끝나면 자식째 끝난다.

## 다시 시작

- **가벼움**: 명령 «저장하지 않고 앱 다시 불러오기»(켤 때 창 비우기가 돈다).
- **완전히**: 옵시디언을 닫고 작업 표시줄 아이콘이 사라진 뒤 다시 연다. 플러그인을 새로 깔았을 때는 이것이 필요하다.
- **탐색기**: 작업 관리자 › Windows 탐색기 › 다시 시작. 우클릭 메뉴 그림·글자를 바꾼 뒤.
