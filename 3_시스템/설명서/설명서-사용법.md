# 사용법

외부뇌는 옵시디언 볼트와 Claude 를 묶은 개인 지식 시스템이다. 받은 자료를 제자리에 두고, 일을 맡기고, 다음에 이어 간다. 목차 = [[사용자설명서]].

## 처음 30분

1. **튜토리얼 한 장** — 홈 › 관리 › 튜토리얼. 토큰을 쓰지 않는다. 1장 «세 자리»가 화면 전체를 보여 준다.
2. **자료 하나 넣기** — 볼트 밖 파일을 우클릭 «외부뇌 받은함으로». → [[설명서-자료-받기]]
3. **Claude 에게 묻기** — 오른쪽 대화창에 볼트 안 내용을 물어본다. → [[설명서-Claude]]
4. **주제 등록** — 과목·프로젝트를 등록해 두면 자료가 그 주제로 모인다. → [[설명서-일정과-주제]]

## 하루 흐름

| 때 | 할 일 | 어디서 |
|---|---|---|
| 켤 때 | 홈에서 받은함·작업·마감을 본다. 어제 창이 필요하면 알림의 «복구» | 홈 |
| 자료가 생기면 | 받은함으로 보낸다. 확실한 것은 저절로 제자리로 간다 | 우클릭 · `Ctrl+Alt+B` |
| 공부·과제 | 문서를 보며 대화창에 묻는다. 보고서는 작업 폴더에서 만든다 | 대화창 · `0_작업` |
| 일이 끝나면 | 홈 «작업»에서 체크한다. 작업 폴더가 비워진다 | 홈 |
| 대화를 마치면 | «세션 종료»라고 말하거나 대화창 더 보기 › «이 대화 기록» | 대화창 |
| 일주일에 한 번 | 홈 «주간 점검» | 홈 |

## 네 층

볼트의 파일은 목적에 따라 네 층으로 나뉜다. 자세히 = [[설명서-화면과-층]]

- `0_작업` 진행 중인 일 — 끝나면 비운다
- `1_수집` 받은 원본 — 내용을 시스템이 고치지 않는다
- `2_지식` 노트와 기록
- `3_시스템` 기계가 쓰는 것

## 묻기와 일

대화창의 새 대화는 **묻기 모드**다. 읽기와 창 다루기만 하고 입력이 작다. 파일을 고치거나 만들어 달라고 하면 **일 모드**로 전환할지 묻는다. 렌치 단추로 미리 켜도 된다. 자세히 = [[설명서-Claude]]

## 잘못했을 때

옮기고 지운 것은 모두 장부에 남고, 지운 것은 30일 동안 휴지통에 있다. 겁내지 말고 써도 된다. 자세히 = [[설명서-되돌리기와-안전]]
