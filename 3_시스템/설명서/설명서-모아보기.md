# 모아보기

목차 = [[사용자설명서]]

수집된 것을 하나씩 열지 않고 한 화면에서 본다. 모아보기는 `.moa` 파일 하나다. 탐색기에서 누르면 탭에 목록이 뜬다. 리본 단추·명령은 없다. 모아보기 파일은 그것이 필요한 자리마다 둔다.

## 찾아보기

| 하고 싶은 일 | 어떻게 |
|---|---|
| 장학을 한눈에 | 탐색기 `2_지식/배움/학교공지/장학/장학.moa` · 수집 창에서 장학 출처를 고르면 이름 옆 «장학» 단추 |
| 칸 너비 바꾸기 | 머리 칸 오른쪽 끝을 끈다(다른 칸은 그대로) · 끝을 두 번 누르면 처음 나눔으로 |
| 학과·단과대 공지를 한눈에 | `2_지식/배움/학교공지/공지.moa` |
| 세부 보기 | 줄을 누른다 — 줄 아래에 펼쳐진다 · 다시 누르면 접힌다 |
| 원문 보기 | 세부의 «원문» 단추 — 옆 칸에 열린다 |
| 정렬 | 칸 머리 글을 누른다 · 다시 누르면 거꾸로 |
| 거르기 | 머리 글 옆 ▾ 에서 값을 고른다 · 이름 옆 칩의 ✕ 로 푼다 |
| 내 상태 적기 | 장학 «상태» 알약(또는 세부의 단추 줄)을 누른다 |
| 지난 것도 보기 | 맨 아래 «지남 4» 를 누른다 |
| 새 모아보기 · 칸 더하기 | Claude 에게 «○○ 모아보기 만들어줘» · «공지에 분야 칸 넣어줘» |

## 보기

- 표 한 장이다. 이름 옆 = 보이는 건수와 걸린 거르기 칩. 마감 칸 = D-n 과 날짜(3일 안 = 빨강 · 7일 안 = 주황).
- 금색 «꽁돈» = 통장으로 현금이 오고 막는 의무가 없는 장학(공지 필터 판정 · 자격 카드 «꽁돈» 칸).
- 정렬은 마감 순으로 시작한다. 값이 없는 줄은 늘 맨 뒤다. 금액은 숫자로 견준다.
- 세부 = 요약 · 마감 · 금액 · 지급(원문 인용) · 의무(원문 인용) · 소득 심사 · 판정 · 출처 · 자격 조건(✓ 맞음 · ? 모름 · ✕ 안 맞음과 원문 인용) · «원문» 단추 · 사람 입력 칸 단추.
- «원문»은 옆 칸에 열고, 다시 누르면 같은 칸에서 바뀐다. 아직 판정 전인 글(볼트 밖 대기 칸)은 일정 줄로 간다 — 그 줄의 [원문] 링크가 사이트 글이다.
- 맨 아래 «지남 4 · 비해당 4» = 거른 줄 수. 누르면 흐리게 펼치고 «접기»로 닫는다.
- 사람 입력 칸(장학 «상태» = 관심·준비·냄·안 냄)은 고른 값이 그 `.moa` 파일에 남는다. «—» 를 고르면 지운다.
- 수집이 새 글을 받거나 판정이 바뀌면 열린 화면이 저절로 다시 그려진다. 자정을 넘기면 다시 열어야 D-n 이 맞는다.
- 보기는 Claude·구독을 쓰지 않는다. 구독이 끊겨도 보인다. Claude 는 모아보기를 만들 때만 쓴다.
- 데스크톱만 된다. 폰은 아직이다.

## 무엇이 나오나

수집 엔진이 볼트에 들인 글과 판정을 기다리는 글(대기 칸)이다. 보관 칸 글과 제목만 남긴 장부 줄은 수집이 이미 뺀 것이라 나오지 않는다. 판정 «비해당»은 기본으로 거른다.

## 새 모아보기 만들기

Claude 에게 «○○ 모아보기 만들어줘»라고 하면 된다. Claude 가 하는 일은 셋이다(공지 모아보기 = 호출 3번 · 정의 172자 · 11-11 잼).

1. `py -3 3_시스템/gather/gather.py sources` — 수집 출처의 id · label · 볼트·대기 글 수를 본다.
2. 필요한 자리에 `<이름>.moa` 를 쓴다. 파일 이름이 탭 이름이다.
3. `py -3 3_시스템/gather/gather.py check <파일>` — 정의를 검사하고 건수를 맞춘다(전부 = 보임 + 거름).

```json
{
  "from": {"collect": {"label": "장학"}},
  "fields": {"상태": {"mine": ["관심", "준비", "냄", "안 냄"]}},
  "columns": ["꽁돈", "제목", "마감", "금액", "지급", "상태"],
  "sort": ["마감"],
  "filters": ["지급", "상태"],
  "hide": {"past": true},
  "strip": "^\\[[^\\]]*\\]\\s*"
}
```

| 칸 | 값 |
|---|---|
| `from.collect` | `label`(조리법 `filter.label` — 장학·공지) 또는 `sources`(출처 id 목록) · `title`(제목 정규식 · 선택) |
| `fields` | 새 칸 — 이름: 규칙 하나 또는 목록(앞에서부터 해 보고 처음 나온 값). 아래 «칸 더하기» |
| `columns` | 표에 보일 칸(순서대로) — 기본 칸 꽁돈 · 제목 · 마감 · 금액 · 지급 · 의무 · 판정 · 출처 · 날짜 · 요약 + `fields` 의 칸 |
| `sort` | 처음 정렬 — 칸 이름 목록 · 앞에 `-` 면 거꾸로 · 값 없음은 맨 뒤(화면에서 머리 글로 바꾼다) |
| `filters` | 머리 글 옆 ▾ 를 달 칸 |
| `hide` | `past`(지난 것) · `verdict`(거를 판정 목록 · 없으면 비해당 · `[]` 면 다 보임) |
| `strip` | 보일 제목에서 뺄 글(정규식) |

### 칸 더하기 (fields 규칙)

| 규칙 | 값 | 예 |
|---|---|---|
| `title` | 제목 정규식 — 묶음 1(없으면 맞은 글) | 공지 분야 `"^\\[([^\\]]{1,6})\\]"` → [졸업] = 졸업 |
| `source` | 출처 이름 · 사전이면 바꿔 부름 | `{"전기전자공학부 학부공지": "전기전자공학부"}` |
| `prop` | 원문 속성 칸 | `"작성자"` |
| `extract` | 공지 필터 판정 캐시 칸 | `"금액"` · `"요약"` |
| `value` | 줄 id → 값 — Claude 가 원문을 읽고 채운다(만들 때만 토큰) | `{"ku-notice-scholarship:…3882": "공대"}` |
| `text` | 고정 값(앞 규칙이 다 비었을 때) | `"기타"` |
| `mine` | **사람 입력 칸** — 값 목록 · 사람이 화면에서 고른다 | `["관심", "준비", "냄", "안 냄"]` |

- 사람 입력 칸의 값은 그 `.moa` 의 `"mine": {"칸": {"줄 id": "값"}}` 에 쌓인다. 화면은 선언한 칸·목록의 값만 쓴다. Claude 가 `.moa` 를 고칠 때 `mine` 은 지우지 않는다.

- 고치기 = 그 파일을 고친다. 열린 화면이 바로 다시 그려진다.
- 지우기 = 그 파일을 휴지통으로.
- 볼트의 모아보기 전부와 건수 = `py -3 3_시스템/gather/gather.py list`.
