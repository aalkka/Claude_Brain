# 찾기

목차 = [[사용자설명서]]

## 어느 길로 찾을까

| 상황 | 길 |
|---|---|
| 낱말이 정확하지 않다 · 내용으로 찾는다 | 대화창에 묻는다 |
| 낱말을 안다 | 옵시디언 검색 `Ctrl+Shift+F` |
| 파일 이름을 안다 | 빠른 전환 `Ctrl+O` |
| 과목·프로젝트로 찾는다 | 탐색기 주제 탭 · 주제 패널 검색 단추 |
| 어떤 노트가 있는지 본다 | `2_지식/MOC.md` · «<주제> 지도 보여줘» |

## 대화창에 묻기

정확한 낱말을 몰라도 된다. 묻기 모드로 충분하다. 지금 보는 파일·고른 글 주변부터 찾고, 그다음 주제 폴더, 볼트 전체 순서로 본다. 답에 근거 파일이 나오면 눌러서 연다. 못 찾으면 «못 찾음»이라고 말한다.

## 옵시디언 검색

`Ctrl+Shift+F`. `path:"1_수집/배움/과목"` 처럼 자리를 좁힐 수 있다. 검색 결과에서 색인을 누르면 색인 대신 원본의 그 쪽이 열린다. `3_시스템` 은 이 설명서만 검색되고 나머지는 빠진다.

## 주제로 찾기

- **주제 탭**: 왼쪽 리본 «외부뇌 주제». 그 주제의 작업·원본·노트·기록이 한 나무로 보인다.
- **주제 패널 검색**: 패널 머리의 검색 단추. 패널에 보이는 목록을 거르고, 목록 밖 파일까지 그 주제 자리에서 찾는다.

## 원본 안 찾기

PDF·문서 내용은 색인으로 찾는다. 색인이 없으면 안 나온다 → [[설명서-자료-받기]] «원본 색인». 열린 문서 안에서는 `Ctrl+F`.

## 찾기 색인(Claude 쪽)

Claude 가 뜻으로 찾을 때 쓰는 색인이다. 결과가 이상하면 홈 행위 «찾기 색인» 또는 `py -3 3_시스템/search.py --rebuild`.

## MOC

`2_지식/MOC.md` = 지식 노트 등록부. 영역(`##`) · 주제(`###`) 아래 노트마다 한 줄. 탐색기에는 안 보이니 `Ctrl+O` 로 연다. Claude 가 새 노트를 만들면 여기에 올린다.
