# 수집 창

목차 = [[사용자설명서]]

수집 본체 화면이다. 모듈이 아니어서 늘 있고, 전체 켜기·끄기와 자동 판정은 설정 «수집»에도 있다. 어떤 수집이 돌고, 무엇을 받고 걸렀는지 한 화면에서 보고, 끄고, 고친다. 수집이 도는지 Claude 에게 묻는 일과 뺄 말·과목을 말로 고치는 일을 없앤다.

- 창이 좁으면(760px 이하) 출처 목록이 위쪽 띠(묶음마다 한 줄 · 출처 칩 · 끝에 점선 «＋ 수집 추가»)로 바뀌고 상세는 그 아래 넓게 뜬다. 왼쪽 곁창이 수집 창 바로 옆에 펴져 있으면 넓어도 위쪽 띠가 된다(brain-base 0.38.3 부터 · 11-06 사용자 1안). 곁창을 접거나 수집 창 왼쪽에 다른 칸이 있으면 나무 그대로다.

## 끄면 무엇이 멈추나

원칙은 하나다. 새 일만 멈추고 받은 것은 그대로 둔다.

| 끄는 것 | 멈추는 것 | 그대로인 것 |
|---|---|---|
| 웹 출처 | 목록 받기 · 글·첨부 받기 · 거르기 · 자동 판정 · 판정 반영 · 보존 | 볼트 글 · 대기 칸 · 장부 · 보관 칸 · 일정 줄(더 안 바뀐다) |
| mylms | 15분 지켜보기 · 신호 받기 · 전 과목 받기 · 로그인 알림 · 06:55 깨우기 | 받은 글·파일 · 내려받기 폴더에 남은 요약 반영 · 쿠키 유지 |
| 과목 | 그 과목 지켜보기·받기 | 받은 자료 |
| 깨우기 | 06:55 PC 깨우기·크롬 띄우기·붙들기(깨우기 예약을 지움) | 15분 반영 |
| 전체 | 위 전부 | 위 전부 |

- 15분 반영 예약은 그대로 돌고 대본이 스위치를 읽어 바로 끝낸다. 15분마다 파이썬이 한 번 뜨는 것은 남는다.
- 06:55 깨우기 예약은 깨우기·mylms·전체 가운데 하나라도 끄면 지워지고 모두 켜면 다시 생긴다. PC 를 깨워 놓고 아무것도 안 하는 일이 없다.
- «깨우기»는 기능 단계 «아침 받기»와 같은 값이다. 어느 쪽에서 바꿔도 같다.
- 스위치 자리: 전체·자동 판정 = `3_시스템/collect.local.json`(이 PC 것 · git 밖) · mylms = `3_시스템/lms/desk.json` · 웹 출처 = 그 조리법. 없으면 전부 켜짐(자동 판정은 끔)이다.
- mylms 스위치는 다음 15분 확인 때 확장에 닿는다. 사람이 크롬 팝업에서 누른 «지금 수집»은 끈 뒤에도 돈다.
- **확장 칸의 «옛 판»**: 확장이 아직 옛 코드다. 이때는 mylms 끄기와 지금 받기가 확장에 닿지 않는다. 크롬을 다시 켜면 새 코드로 올라온다. 표시는 다음 요약이 올 때 풀린다.
- 크롬 팝업의 «지켜보기» 스위치는 따로다. 둘 중 하나라도 끄면 멈추고, 창은 팝업 값을 못 읽는다.

## 고치는 칸

| 칸 | 범위 |
|---|---|
| 목적 | 글 · 동작에 영향 없음 |
| 뺄 말·남길 말 | 낱말 그대로 넣는다 · 점선 칩은 정규식이라 창에서 못 뺀다 · 새 글부터 · 남길 말은 하나는 남아야 한다 |
| 주기 | 1~24시간 |
| 쪽 | 1~9 |
| 첨부·그림 | 켜고 끄기 · 크기 제한은 보기만 |
| 자동 판정 | 목록 위 전체 스위치 · 기본 끔 · 켤 때 묻는다 · 켜도 조리법 `filter.auto: false` 인 출처는 뺀다 · 다음 돌림부터 |
| 과목 | 스위치 · 폴더 이름은 안 고친다 |

주소·정규식·가족·계약 문구·폴더는 창에서 고치지 않는다. 고장 나면 Claude 보수 몫이다. 고친 값은 조리법 파일에 들어가고 `git` 에 남으며, 행위는 장부에 남는다.

## 글 줄 단추

숫자 칸을 누르면 그 자리의 글이 나온다. 줄에 마우스를 올리면 단추가 보인다.

| 자리 | 단추 | 뜻 |
|---|---|---|
| 볼트 | 헛것 · 쓸모 | 표시만 한다. 쓸모 표시 글은 보존·보관이 건드리지 않고, 규칙이 비해당으로 판정해도 일정에 남는다 |
| 판정 대기 | 빼기 | 대기 칸에서 지우고 장부 한 줄만 남긴다. 사용량 없음 |
| 대기 칸·장부 | 살리기 | 볼트로 들인다. 장부 글은 본문을 안 받았으니 이때 받는다. 쓸모 표시가 함께 남는다. 추출이 없던 글의 마감은 다음 판정 때 일정에 잡힌다 |
| 보관 칸 | 되돌리기 | 볼트 같은 자리로 |

끈 출처에는 살리기·판정·지금 받기가 없다. 글을 받거나 판정 반영이 도는 일이어서다. 켜면 다시 보인다.

## 판정·받기

- **판정 N**: 그 출처의 판정 대기 글만 추출한다. 구독 사용량이 들어 누를 때만 돌고, 구독이 아니면 멈춘다.
- **지금 받기**: 웹 출처는 그 자리에서 받는다. mylms 는 PC 에서 확장으로 가는 길이 `known.json` 하나뿐이라 다음 15분 확인 때 돌고, 그동안 «받기 대기»가 보인다. 크롬이 꺼져 있으면 켜질 때까지 기다린다.
- 15분 예약과 겹치면 «다른 수집이 도는 중»이라고 말하고 안 돈다. 잠시 뒤 다시 누른다.

## 로그인·후보

- 창은 비밀번호를 다루지 않는다. 로그인 단추와 주소 글자는 페이지를 열기만 한다. mylms 는 확장이 있는 크롬으로 연다.
- 후보 줄은 Claude 가 조사해 `3_시스템/lms/candidates.json` 에 적은 새 출처다. 계약을 누르면 대기열에 한 줄이 생기고, Claude 가 조리법을 탐색해 쓴 뒤에야 돈다. 안 함을 누르면 줄이 사라진다.
- 조리법이 생기면 후보 줄은 사라지고 출처 줄이 대신한다.

## 수집 추가·고침

- «＋ 수집 추가»를 누르면 대화창이 새 대화로 열리고 첫 질문(무엇을 모으려 하는지 · 주소를 알면 함께)이 뜬다. 이 질문은 Claude 를 부르지 않는다. 답을 보내야 Claude 가 시작한다 — 잘못 눌러도 사용량이 들지 않는다.
- 그 뒤 Claude 가 한 단계씩 묻는다: 목적을 정리해 확인 → 주소(모르면 후보를 찾아 줌) → 최근 글 미리보기(저장 없음) → 남길 말·뺄 말 → 주기·저장 자리·알림 → «추가하시겠습니까?». «추가»라고 답하기 전에는 수집이 돌지 않는다.
- 지금 넣을 수 있는 것: 공개 게시판 목록 · RSS 피드. 유튜브 채널 피드는 YouTube robots 가 막아, 넣을 때 사용자가 그 채널을 받기로 정해야 한다. 로그인 사이트·메일은 아직 없다.
- robots.txt 가 막은 사이트는 막혔다는 것을 보여 주고 넣을지 묻는다. 넣기로 하면 그 답이 계약 문구에 남는다.
- 판정 층이 없는 출처(블로그 등)는 «구독» 묶음에 뜨고, 남길 말·뺄 말 칩으로 제목만 보고 고른다. 걸린 글은 장부 줄로 남아 살릴 수 있다.
- 출처가 깨지면(목록이 안 읽힘 등) 줄이 빨갛게 «실패»가 되고 실패 줄 끝에 «고침»이 뜬다. 누르면 대화창에 실패 내용과 «고칠까요?»가 뜨고(Claude 호출 없음), 답을 보내면 Claude 가 조리법의 구조만 고친다. 목적·낱말·자리·주기는 고침이 바꾸지 않는다.

## 창이 못 보는 것

- 확장의 15분 확인 시각은 PC 에 안 닿는다. «마지막»은 PC 로 온 마지막 요약이다.
- 공휴일은 끌 칸이 없다. 주간 점검이 30일에 한 번 받는다.
