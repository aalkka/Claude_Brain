# 작업과 기록

목차 = [[사용자설명서]]

## 작업 폴더

진행 중인 일만 두는 곳이다(`0_작업/<영역>/<주제>/<작업>`). **끝나면 비운다.** 예외는 없다.

**만들기**: 탐색기에서 주제 우클릭 › «작업 폴더 만들기» · Claude 에게 맡기기. 주제 폴더 바로 아래의 폴더나 md 파일 하나가 작업 하나다.

## 끝냄 체크

**홈 «작업»**에 작업 폴더의 작업이 모두 보인다. 줄 왼쪽 칸을 체크하면 «작업을 끝내시겠습니까?»라고 한 번 더 묻고, «끝냄»을 누르면 바로 비워진다. «취소»·`Esc` 는 그대로 둔다. 줄을 누르면 탐색기에서 보여 준다. 탐색기 우클릭 «끝냄»은 묻지 않고 바로 비운다.

오른쪽 글: `N일`(안 바뀐 날) · `마감 지남` · `멈춤`(7일 안 바뀜) · `보냄` · `결과물 없음`.

**비울 때 어디로 가나**

| 파일 | 어디로 |
|---|---|
| 보낸 결과물 | 원본 층 `<영역>/<주제>/보냄/`(학교 과목은 `제출/`) |
| md 노트 | `2_지식/<영역>/<주제>/<작업>/` |
| 그림·측정 같은 재료 · 다시 못 만드는 것 | 결과물 옆 또는 지식 층 |
| 대본·만든 그림·임시 파일 · md 에서 내보낸 문서 | 휴지통(30일) |
| 학교 보고서 | PDF 만 제출에 · docx·재료는 휴지통 |

**되돌리기**: 비운 뒤 오른쪽 위 알림 «비움 · 이름»의 «되돌리기». 놓쳤으면 장부에서 → [[설명서-되돌리기와-안전]].

## 저절로 비우기

볼트를 켤 때 근거가 확실한 작업은 체크 없이 비운다. 윈도 알림과 «되돌리기»가 뜬다.

| 근거 | 무엇 |
|---|---|
| LMS 내 제출 | 제출한 파일 이름이 작업 안 파일과 맞음 |
| `작업.md` 표시 | `단계: 끝` · `단계: 제출` · `보냄: 메일 · 받는 곳` |
| 저장소 | `저장소:`·`가지:` 를 적은 가지가 병합됨 |

아래는 저절로 비우지 않는다. 아직 하는 중일 수 있어서다. 끝났으면 체크한다.

- **마감 지남** · **멈춤**
- **결과물 없음**: 보냈다고 했는데 결과물을 어디서도 못 찾음
- 비웠다가 되돌린 작업

## 보존 일정표

무엇을 얼마나 두는지 정한 표다. 홈 › 관리 › 보존 일정표에서 «날»을 고치면 다음 실행부터 따른다.

## 세션 기록

Claude 와의 작업을 다음에 이어 가기 위한 기록이다.

- **남기기**: «세션 종료» · «정리해줘» · 대화창 더 보기 › «이 대화 기록». 크기에 따라 세션 노트 · 한 줄 · 생략 중에 고른다.
- **놓쳤으면**: 다음 세션이 «기록이 남지 않은 세션»을 알린다. «기록»이라고 하면 처리한다.
- **어디에**: `2_지식/기록/` · 최근 한 줄 = `recent.md` · 진행 중인 일 = `open-loops.md`.

## 진행 중 · 최근 세션

홈 «기록»에서 읽는다. 새 세션을 열면 Claude 에게 저절로 들어간다. 끝난 일은 Claude 가 지우고, Claude 가 못 알아챈 것은 `- [ ]` 를 `- [x]` 로 바꾸면 다음 세션에 지워진다.

## 주간 점검

홈 행위 «주간 점검»(`/weekly-review`). 주 1회 시스템과 밀린 일을 점검한다.

## 정리 후보

같은 내용 사본 · 빈 파일 · 빈 폴더 · 고아 첨부를 후보로만 보여 준다. 홈 행위 «정리 후보».

## 자동 저장

- **커밋**: 턴마다 자동(`session:` 커밋). 메시지가 짧은 것은 정상이다.
- **push**: 세션 시작·끝.
- **원본 파일**(`1_수집` 의 PDF 등)은 git 에 안 올라간다. 따로 챙긴다.
