# 분류와 알림

목차 = [[사용자설명서]]

무엇을 어느 갈래에 둘지(분류), 거기에 표를 붙일지(태그), 폰을 울릴지(알림)를 규칙 하나로 정해 두면 수집이 돌 때마다 저절로 맞춘다. 공지마다 «이거 꽁돈인가» 따지는 일과 가격 비교 사이트를 손으로 뒤지는 일을 없앤다. 규칙은 말로 주고, Claude 가 옮겨 적는다.

## 찾아보기

| 하고 싶은 것 | 이렇게 |
|---|---|
| 규칙 말하기 | 대화창에 «장학 중 통장으로 현금 주면 꽁돈 태그 붙여» · «SSS 뜨면 바로 알려 줘» — Claude 가 적기 전에 바뀌는 글 목록을 먼저 보인다 |
| 이 글 하나만 꽁돈으로 | 대화창에 «이거 꽁돈» — 판정자가 «사람»으로 남는다 · «꽁돈 아님»도 같다 |
| 규칙 보기 | 수집 창 출처 상세 «규칙» 칸 · 대화창 «꽁돈 규칙 보여줘» |
| 판정 맡기기(Claude) | 수집 창 출처 머리 줄 «판정 N»(구독 사용량) |
| 자동 채택 되돌리기 | 수집 창 알림 줄 «되돌리기» |
| 꽁돈 · 티어 보기 | 일정 줄 `#꽁돈` · 장학 모아보기 꽁돈 칸 · 수집 창 한 줄 맨 앞 |
| 분류 알림 보기 | 수집 창 출처 «일어난 일»의 ✦ 줄(누르면 글 · 때 · 폰에 냈나) · 폰 알림 카드 |
| 알림 끄기 | 대화창 «○○ 알림 꺼 줘»(그 갈래의 알림 동작을 뺀다) · 폰만 = 폰 앱 «이 기기만 끄기» · 전부 = 알림-설정 «켬» |
| 태그 뜻 보기 | 대화창 «태그 사전 보여줘»(행위 `tag.list`) |
| 지금 하나 알리기 | 대화창 «지금 폰으로 알려 줘 — …» (행위 `mobility.alert_now` · 급함이면 밤에도 · 모바일 연결(mobility) 모듈의 행위) |

## 세 도구

- **분류** — 대상(수집 글 · 가격 줄) 하나와 체계 하나를 보고 갈래 하나를 정한다. 판정 차례는 ① 지난 판정 기억 → ② 코드 규칙 → ③ 낱말 통계(기본 끔) → ④ Claude(버튼). 규칙 원본은 체계 파일 `3_시스템/sort/<체계>.json` 하나이고, 규칙마다 사용자가 한 말이 그대로 적혀 있다.
- **태그** — 분류가 정한 표를 그 대상이 보이는 자리에 붙인다. 붙일지는 분류가 정한다.
- **알림** — 분류가 «알림»으로 정한 것을 때에 맞춰 폰과 수집 창에 낸다. 울릴지·급한지는 분류가 정한다.

## 태그가 보이는 자리

| 대상 | 자리 | 원본 |
|---|---|---|
| 수집 글(공지·장학) | 일정 줄 `#꽁돈` · 판정표 «꽁돈» · 수집 창 한 줄 맨 앞 · 모아보기 꽁돈 칸 | `1_수집` 원본은 안 고친다(겹쳐 보이기) |
| 가격 줄(항공권) | 수집 창 · 모아보기 | 볼트 밖 가격 장부 |
| 노트(`0_작업` · `2_지식`) | 프론트매터 `tags` | 체계가 «노트에 쓰기»를 켰을 때만(기본 끔) |

- 겹쳐 보인 태그는 옵시디언 태그 검색에 안 잡힌다.
- 노트에 쓸 때는 도구가 붙인 것만 뗀다. 사용자가 먼저 단 같은 태그는 건드리지 않는다.
- 태그 사전 = `3_시스템/sort/태그/사전.json` — 뜻 · 순서 · 가족(`티어/SSS` … `티어/C` · 앞이 높음). 어느 체계가 쓰는지는 체계 파일에서 센다.

## 알림

- **때**: «바로»(지금) · «아침»(다음 잘 시간 끝) · «묶음 08:00»(다음 그 시각). 잘 시간(알림-설정 «잘_시간» · 기본 23:00~08:00)에 떨어지면 아침으로 미룬다. 급함이면 밤에도 바로 울린다(항공권은 SSS 만).
- **중복**: 같은 글·같은 갈래는 한 번만 울린다. 갈래가 오르면(티어 S → SS) 다시 울리고, 내려가면 안 울린다. 사라졌다 다시 나온 것은 새것이다. 횟수 상한은 없다.
- **여럿**: 한 번에 여럿이면 폰 알림 카드 한 장에 넘겨 본다(점 · 7개 넘으면 «k / n») — 높은 갈래부터.
- **전달**: 알림 도구는 모바일 연결(mobility) 모듈 몫이다(11-18). 폰은 45분마다 PC 에서 당겨 온다(«바로» = 늦어도 약 45분 · 즉시 알림 시험판은 붙잡아 둔 연결로 바로). mobility 모듈이 꺼져 있으면 알림 도구는 돌지 않고, 수집 창 «일어난 일»에 분류가 정한 알림 줄만 남는다.
- **누름**: 폰 알림을 누르면 체계의 모아보기가 열린다(없으면 옵시디언 홈). 항공권 예약 주소는 수집 창 줄에 남는다.

## 켜고 끄기

- 체계 하나 = 체계 파일 `"켬": false`. 꺼진 체계는 판정·태그·알림이 모두 멈춘다(지난 판정은 남음).
- 노트에 태그 쓰기 = 체계 파일 `"노트에 쓰기": true`(기본 없음 = 끔). 끈 뒤 도구가 붙여 둔 태그를 떼려면 «태그 다시 맞춰 줘»(`tag.py sync --all`).
- 알림 하나 = 그 갈래 동작에서 `{"알림": …}` 를 뺀다. 폰 전부 = 알림-설정 «켬» · 이 폰만 = 폰 앱 «이 기기만 끄기».
- 15분 확인 끝에 태그·알림이 저절로 맞춰진다. 바로 보고 싶으면 «태그·알림 지금 맞춰 줘».
- 가격 조회(예: 항공권) 체계·조리법은 처음에 꺼져 있다. 켜는 것은 Travelpayouts 토큰을 넣은 뒤다([[설명서-수집]] «개인 파일 만들기»).

## 한계

- 노트 대상 어댑터가 아직 없어 «노트에 쓰기»를 켤 체계가 없다(수집 글·가격 줄은 겹쳐 보이기만).
- 사람 태그(«이거 꽁돈»)는 그 글의 입력(본문 · 추출)이 바뀌면 규칙이 다시 정한다.
- 규칙 적기는 대화창에서만 된다(수집 창 단추 없음).
