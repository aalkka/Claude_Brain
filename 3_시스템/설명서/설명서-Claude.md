# Claude 에게 묻고 맡기기

목차 = [[사용자설명서]]

대화창은 오른쪽 곁창이다. 왼쪽 리본 말풍선 · 명령 «대화창 열기». Claude Code 가 설치되어 있어야 한다(구독 로그인 그대로).

## 묻기 모드와 일 모드

| | 묻기 모드 | 일 모드 |
|---|---|---|
| 켜기 | 새 대화 기본 | 머리의 렌치 단추 |
| 하는 일 | 읽고 답하기 · 창 다루기 | 제작: 파일 고치기·만들기·옮기기·지우기 · 스킬 · 명령 실행 · 웹 |
| 첫 입력 | 약 4,100 토큰 | 볼트 규약 전체 · 약 9배 |

묻기 모드에서 제작을 부탁하면 «일 모드로 전환하시겠습니까?» 카드가 뜬다. «전환»이면 다시 말하지 않아도 같은 대화를 일 모드로 이어 가고, «취소»면 묻기 모드에 머문다. 일이 끝나면 «새 대화»로 돌아간다. 설정 «새 대화 = 묻기 모드»로 기본을 바꾼다.

## 저절로 붙는 것

보내는 질문에 함께 간다. 입력 상자 위 칩으로 보이고, 칩을 누르면 뺀다.

- 지금 연 파일(경로만 · 내용은 Claude 가 필요할 때 읽음)
- 고른 글 · PDF 면 보는 쪽
- 그 파일의 주제 · 연관 노트

## 상자 고르기

화면 일부를 보이며 묻는다. 입력 상자의 상자 단추(명령 «상자 고르기») → 창 위에서 끌기 → 칩이 붙는다. `Esc`·오른쪽 단추 = 취소.

- 글만 있고 글자가 더 싸면 글자로 간다. 칩의 화살표로 그림·글자를 바꾼다.
- 칩의 숫자 = 쓰는 토큰(그림 = 가로×세로÷750 · 글자 = 영어 0.33·한글 1.07/자).
- «작음»이 뜨면 글자가 작아 못 읽을 수 있다. 확대한 뒤 다시 고른다.
- 새 창(팝아웃) 안은 못 고른다.

## 창 다루기

대화창에 말로 시킨다: 탭 열기·바꾸기 · 스크롤(끝·쪽·표제) · 화면 나누기 · 옮기기 · 닫기 · 뒤로 · 곁창 접기. 승인 없이 되고 파일 내용은 건드리지 않는다. 설정 «대화창 화면 도구»로 끈다.

## 맡기기

그냥 말로 시킨다. 묻기 모드면 일 모드 전환을 먼저 묻는다. 고치기 전에 승인 카드가 뜰 수 있다.

- **승인 카드**: 허용 · 이 대화 동안 허용 · 거부(설정 «승인 방식»).
- **바뀐 파일**: 답 끝에 고친 파일 목록과 «되돌리기». 고친 뒤 또 바뀌었으면 되돌리지 않는다.
- **멈춤**: 보내기 단추가 네모로 바뀐다. 누르면 멈춘다.
- **기다릴 때**: 지금 하는 일 낱말(생각 중 · 도구 이름 · 승인 기다림 · 마무리 중)과 경과 초가 보인다.

## 모델과 노력

입력 상자 아래에서 고른다. 모델은 별칭(Opus·Sonnet·Haiku)이라 새 판이 나오면 따라간다. 노력 «자동» = 질문마다 길잡이가 고른다.

## 맥락과 사용량

입력 상자 아래 계기.

- **맥락**: 지금 대화 크기. 길수록 한 마디가 비싸진다. 누르면 구성을 본다.
- **세션·주 %**: 구독 사용량. 누르면 자세히.
- **캐시 N분**: 시간이 지나면 캐시가 식어 다음 입력이 비싸진다.
- 맥락이 커지면 «이어서 새로»를 권한다.

## 대화 끝내기·이어 가기

머리 «더 보기».

| 항목 | 하는 일 |
|---|---|
| 지난 대화 이어 가기 | 마지막 대화를 다시 연다 |
| 이어서 새로 | 지난 대화의 색인만 붙여 새로 연다(요약 없음 · 토큰 0) |
| 이 대화 기록 | 세션 노트를 남긴다(`/session-record`) |
| 대화 끝내기 | 엔진을 닫는다 |

주제 패널·탐색기 «이 주제로 Claude» = 그 주제 카드를 붙여 새 대화. 작은 지난 대화가 있으면 이어 간다.

## 볼트 밖에서

스킬·브라우저·메일처럼 큰 일은 일 모드나 Claude Code 앱에서 한다. 같은 볼트 규약·기억이 돈다.
