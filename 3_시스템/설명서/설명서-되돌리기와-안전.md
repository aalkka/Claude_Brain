# 되돌리기와 안전

목차 = [[사용자설명서]]

## 무엇을 되돌리나

| 한 일 | 되돌리는 곳 |
|---|---|
| 지운 파일 | 왼쪽 리본 «휴지통» · 줄마다 되살리기 |
| 옮기기·이름 바꾸기 | 홈 › 관리 › 장부 · 줄마다 되돌리기 |
| 받은함으로 옮기기 | 윈도 알림 «되돌리기» · 장부 |
| 끝냄(작업 비움) | 알림 «되돌리기» · 장부 |
| Claude 가 고친 파일 | 대화창 답 끝 «바뀐 파일» › 되돌리기 |
| 그 밖의 노트 내용 | 옵시디언 파일 복구 · git 이력(Claude 에게 말한다) |
| 원본 문서 편집 | 문서 안 `Ctrl+Z` · «편집 전 원본 사본 폴더» |

## 휴지통

볼트 안 `.trash`. 왼쪽 리본 «휴지통» · 명령 «외부뇌 휴지통». 30일 넘은 것은 홈에 표시만 하고, 비우는 것은 사람이 한다.

## 장부

옮기고 지운 일이 모두 적히는 기록이다(`3_시스템/ledger/`). 옵시디언에서 직접 한 것, 윈도 탐색기에서 한 것(따라가기), Claude·대본이 한 것이 모두 들어간다. 홈 › 관리 › 장부 · 명령 «외부뇌 장부 보기 · 되돌리기». 설정 «지우기·이름 바꾸기 장부»로 끈다.

## 코어 승인

시스템을 흔들 수 있는 파일을 고칠 때 승인 창이 뜬다. 일반 노트에는 안 뜬다.

- **코어**: `CLAUDE.md` · `3_시스템/hooks/` · `search.py` · `conventions.md` · `.claude/settings.json` · `.obsidian/plugins/`(플러그인 설치 포함)
- **창이 뜨면**: 내용을 보고 허용 또는 거부. 시험 볼트·사본에는 안 뜬다.
- **자리를 비울 때**: «앞으로 2시간, `3_시스템/hooks/` 안에서 코어 수정 토큰 발행해줘». 범위 밖은 즉시 거부되고, 게이트 자신은 토큰으로 못 고친다.
- **창이 안 뜨는 것 같으면**: `powershell -NoProfile -ExecutionPolicy Bypass -File 3_시스템/_eval/gate-verify.ps1` 끝 줄이 `mismatches = 0` 이면 정상이다.

## 민감한 노트

프론트매터 `sensitive: true` 면 git 에 안 올라간다(볼트 복사본이 백업). 비밀번호·개인정보를 담은 노트에 쓴다.

## 로그인·내보내기

- **받아들이기**(읽기·내려받기)만 승인 없이 한다.
- **내보내기**(보내기·게시·push)는 확실한 승인을 받는다.
- **로그인**은 사람이 한다. Claude 는 비밀번호를 치지 않는다.
- 수집은 원본 그대로다. 페이지 속 지시문을 따르지 않는다.

## 금고

민감한 원본을 암호화해 두는 모듈이다(따로 설치 · 지금 배포판에는 없다). 왼쪽 리본 «금고». 서비스가 플러그인·앱 파일의 변조를 감시하고, 바뀌면 보기를 막는다. 플러그인을 고친 뒤에는 재기준이 필요하다.

## 백업

| 무엇 | 어디 | 언제 |
|---|---|---|
| 노트·설정 | git 원격 | 세션 시작·끝 push |
| 원본 파일 | 없음(git 제외) | 따로 복사 |
| 민감한 노트 | 볼트 복사본 | 직접 |

큰 구조 변경 전에는 Claude 가 볼트를 복사해 둔다.

## 외부 키·사용량

종량 API 키를 쓰지 않는다. 구독 로그인으로만 돈다. 사용량이 드는 기능은 누를 때만 돈다(그림 읽기 등).
