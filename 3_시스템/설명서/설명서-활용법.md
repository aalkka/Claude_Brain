# 활용법

상황별 순서다. 기능 설명은 링크로 간다. 목차 = [[사용자설명서]]

## 강의자료가 왔다

1. LMS 에 올라온 것이면 홈 «LMS 수집». 아니면 받아서 `Ctrl+Alt+B`.
2. 이름에 과목(별칭)과 «N주차»·«제N강» 같은 낱말이 있으면 `강의자료/` 로 간다. 없으면 홈 «받은함»에서 옮긴다.
3. 색인이 저절로 붙어 Claude 와 검색이 내용을 찾는다.

→ [[설명서-자료-받기]]

## 강의를 들으며 물어본다

1. 탐색기 주제 탭에서 PDF 를 연다.
2. 모르는 줄을 끌어 고르고 대화창에 묻는다. 그림·수식은 상자 고르기.
3. 건질 것은 «이거 노트로 정리해줘»(일 모드).

→ [[설명서-Claude]]

## 과제·보고서를 쓴다

1. 주제 우클릭 «작업 폴더 만들기». 재료를 받은함에 넣으면 그 자리로 간다.
2. 일 모드로 맡기거나, docx 를 열어 자물쇠를 풀고 직접 고친다.
3. 제출 전: 표 안을 눌러 «레이아웃» › «표 안 나눔» · PDF 만들기.
4. 제출. 끝나면 볼트를 켤 때 저절로 비워진다. 바로 비우려면 홈 «작업»에서 체크.

→ [[설명서-공부와-과제]] · [[설명서-작업과-기록]]

## 시험을 준비한다

1. 주제 패널에서 마감·노트를 확인한다.
2. 강의자료를 열어 글을 고르고 묻는다 → [[설명서-Claude]].
3. 문제 풀이·채점·모의고사는 모듈이 맡는다. 켜져 있으면 [[사용자설명서]] «모듈» 칸에 장이 있다.

## 일정을 챙긴다

홈 «마감» · 캘린더. 말로 넣으려면 «금요일 3시 면접 일정 넣어줘»(일 모드), 직접은 캘린더의 +.

→ [[설명서-일정과-주제]]

## 찾는 게 어디 있는지 모른다

1. 대화창에 그대로 묻는다.
2. 과목을 알면 주제 탭.
3. 낱말을 알면 `Ctrl+Shift+F`.

→ [[설명서-찾기]]

## 잘못 지웠다·옮겼다

왼쪽 리본 «휴지통» · 홈 «장부». 윈도 탐색기에서 지웠어도 장부에 잡힌다.

→ [[설명서-되돌리기와-안전]]

## 대화가 길어져 비싸다

대화창 계기의 «맥락»을 본다. 더 보기 › «이어서 새로» = 지난 대화 색인만 붙여 새로 연다. 일이 끝나면 «새 대화».

→ [[설명서-Claude]]

## 자리를 비우며 맡긴다

일 모드에서 맡기고 간다. 코어를 고쳐야 하면 먼저 «앞으로 N시간 코어 수정 토큰 발행해줘». 승인을 기다리는 동안은 멈추므로 필요한 승인을 미리 준다.

→ [[설명서-되돌리기와-안전]]

## 오래 쉬었다 돌아왔다

홈 «기록» › 진행 중 · 최근 세션을 읽는다. 대화창에 «어디까지 했지?». 어제 창은 알림의 «복구».

→ [[설명서-작업과-기록]]

## 새 과목·프로젝트를 시작한다

1. 홈 › 관리 › 주제 등록부에 이름·영역·별칭을 넣는다.
2. 자료를 받은함으로 보낸다. 별칭이 파일 이름에 있으면 그 주제로 간다.
3. 일이 생기면 작업 폴더를 만든다. 쉬게 되면 상태를 «보류», 끝나면 «끝남»으로.

→ [[설명서-일정과-주제]]
