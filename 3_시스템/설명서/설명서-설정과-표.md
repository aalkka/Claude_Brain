## 행위

시스템 일을 이름으로 실행한다. 명령 «외부뇌 행위 고르기…» · 홈 «행위». 각각 장부에 남는다. 목록의 진실 원본은 `py -3 3_시스템/brain.py list`.

| 묶음 | 행위 |
|---|---|
| 찾기 | 볼트에서 찾기 · 찾기 색인 다시 · 원본 색인 다시 |
| 일정 | 일정 다시 만들기 · 공휴일 표 다시 받기 · 이번 주 일정 |
| 수집 | LMS 수집 · 웹 공지 수집 |
| 파일 | 옮기기·이름 바꾸기 · 휴지통으로 · 되살리기 · 되돌리기 · 장부 최근 · 휴지통 보기 |
| 받은함 | 보기 · 분류 제안 · 정리 · 항목 하나 · 받는 문 상태 · 볼트 밖 후보 |
| 작업 | 작업 폴더 상태 · 끝난 작업 정리 계획 · 정리 후보 |
| 따라가기 | 바깥 변화 따라가기 · 사라진 것 받아들이기·되받기·그대로 |
| 주제 | 주제 카드 |

켜진 모듈의 행위는 이 뒤에 붙는다.

## 설정(Brain Base)

설정 › 커뮤니티 플러그인 › Brain Base. 맨 위 «단계»(기능마다 높음·낮음·끔 · 이름을 누르면 대가와 추천 까닭) 다음에 묶음 일곱 — 묶음마다 제목 + 카드 한 장. 칸이 비면 기본값이고 지금 값은 흐린 글로 보인다. 이름 옆 ⟲ 는 다시 켜야 먹는 줄.

| 묶음 | 설정 | 뜻 |
|---|---|---|
| 대화창 | 새 대화 = 묻기 모드 · 연 노트 붙이기 · «이어서 새로» 맥락(토큰) | 새 대화의 처음 모드 · 질문에 지금 파일 경로 · 권할 크기 |
| 일 모드 | 승인 방식 · 도구 줄이기 · 화면 도구 | 묻기 모드에서는 듣지 않는다 |
| 탐색기 | 기본 탐색기 대신 쓰기 · 누르면 새 탭 · 연 파일 따라가기 · 노트를 제목으로 | 끄면 옵시디언 탐색기 · 탐색기 동작 · 펼치기 · 속성 title |
| 노트 | 새 노트 속성 표 · 새 노트 MOC 등재 · 지우기·이름 바꾸기 장부 | 새 노트 처리 · 장부에 적기 |
| 켤 때 | 홈만 ⟲ · 상태 막대 건강 ⟲ | 창 비우기·곁창 접기 · 오른쪽 아래 ✓ △ ✗ |
| 연결 | claude 경로 · 파이썬 · 작업 폴더 | 비우면 찾아서 · `py -3` · 이 볼트 |
| 자리 | 지난 대화 색인 폴더 | 비우면 `3_시스템/_index/stubs` |

Brain Source: 원본 화면 · 원본 편집 · 색인 · 탐색기(옵시디언 기본 탐색기를 쓸 때만) · 연결(파이썬) · 자리(원본 폴더 · 색인 폴더). Brain Calendar: 자리(일정 폴더 · 적는 파일).

## 배치

리본·곁창 배치를 파일(`3_시스템/default-layout.json`)로 둔다. 명령 «외부뇌 지금 배치를 기본으로» = 지금 배치를 저장 · «외부뇌 기본 배치로» = 되돌리기. 새로 깔 때 한 번 적용되고, 업데이트는 덮지 않는다.

## 모듈

기능 묶음이다. 홈 «모듈»에서 켜고 끈다. 오른쪽 숫자 = 상시 토큰(대화마다 드는 입력). 이 PC 에만 적용된다.

| | 끄면 | 켜면 |
|---|---|---|
| 스킬 | 다음 대화부터 없음 | 다음 대화부터 |
| 화면 · 리본 · 명령 · 행위 · 건강 줄 · 기록 단계 · 튜토리얼 · 설명서 장 | 바로 없어짐 · 열린 화면은 닫힘 | 재시작 없이 돌아옴 |
| 모듈이 쌓은 자료(`2_지식/modules/<모듈>/`) | 그대로 남아 탐색기·검색에 보임 | 이어서 쓴다 |

끄면 그 모듈이 하던 일만 안 된다. 코어 기능은 막히지 않는다. dist-sync 를 끄면 새 판을 못 받고, module-forge 를 끄면 모듈 건강 줄의 정적 검사가 빠진다.

켜진 모듈의 설명서 장은 [[사용자설명서]] «모듈» 칸에, 튜토리얼 장은 코어 장 뒤에, 찾아보기 줄은 [[찾아보기]] «모듈» 칸에 합쳐진다.
