# 글씨체 사전 (그림 소화의 손글씨 읽기용)

`ingest.py --vision`(→ `ingest_vision.py`)이 그림을 Claude 에게 보낼 때마다 이 사전을 앞에 붙인다. 사전이 바뀌면(판 = 내용 해시) 손글씨가 있던 그림만 다시 읽는다. 결정·근거 → [[외부뇌-원본형식-수용]] (2026-10-15: claude -p · sonnet 5.5 · 표본 = 사용자 필기).

## 파일
- `profile.md` — 글자 버릇(«ㄹ 을 2 처럼 씀»), 헷갈리는 쌍(«1 ↔ 7», «v ↔ ν»), 기호·약어(«∴», «w/», 화살표 뜻), 줄 배치 습관. **짧게** — 호출마다 실린다(1,000자 ≈ 600토큰 × 장 수).
- `samples.json` — `[{"image": "samples/xx.png", "text": "정답 전사"}]`. 표본 그림은 **한 줄~몇 줄 크기로 잘라** 둔다(그림 한 장 ≈ 1,500토큰이 호출마다 실리므로 3~6장 이내).
- `samples/` — 표본 그림. 사용자 필기라 git 에 올리지 않는다(원본 git 제외 결정과 같음 · `.gitignore` 반영은 표본을 처음 넣을 때).

**아직 비어 있다** — `profile.md`·`samples.json` 이 없으면 사전 없이 읽는다(판 = 빈 값).

## 만드는 순서
1. 사용자가 필기 사진을 준다(`1_수집/받은함/` — 필기도 원본이라 그대로 수집 대상).
2. Claude 가 세션에서 꼼꼼히 전사하고, 헷갈린 글자만 골라 사용자께 묻는다(원격이면 대화창에).
3. 확인된 전사에서 ①자주 틀린 글자·버릇 → `profile.md` ②대표 줄 3~6개를 잘라 `samples/` + `samples.json`.
4. `py -3 3_시스템/ingest.py --vision` — 사전 판이 바뀌었으니 손글씨 그림만 다시 읽는다.
5. 이후 오독을 고쳐 주시면 2~4 를 되풀이(사전에 쌓임).
