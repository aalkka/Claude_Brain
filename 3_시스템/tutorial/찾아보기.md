# 외부뇌 찾아보기

해 보는 것은 튜토리얼(홈 › 관리 › 튜토리얼)이고, 이 파일은 다시 찾을 때 본다. 자세한 설명은 [[사용자설명서]] 목차의 장으로 간다. 대화창의 Claude 도 사용법 질문에 답할 때 이 파일을 읽는다.

## 규칙

- **층**: `0_작업` 진행 중 · `1_수집` 받은 원본(내용을 시스템이 고치지 않음) · `2_지식` 노트 · `3_시스템` 기계.
- **묻기 모드와 일 모드**: 새 대화는 묻기 모드다. 읽기와 창 다루기만 하고 입력이 작다. 제작을 부탁하면 일 모드 전환을 묻는다. 일 모드는 볼트 규약 전체를 읽어 입력이 약 9배 크다.
- **지우기**: 볼트에서 지운 것은 30일 휴지통으로 간다. 끝났지만 남길 노트는 `status: archived`.
- **민감한 노트**: 프론트매터 `sensitive: true` 면 push 에서 빠진다.
- **코어 파일**: `CLAUDE.md`·`3_시스템/hooks/`·`search.py`·`conventions.md`·`.claude/settings.json`·`.obsidian/plugins/` 를 고칠 때 승인 창이 뜬다. 일반 노트에는 안 뜬다.
- **자리를 비울 때**: «앞으로 2시간, `3_시스템/hooks/` 안에서 코어 수정 토큰 발행해줘». 범위 밖은 즉시 거부되고, 게이트 자신은 토큰으로 못 고친다.
- **백업**: 커밋은 턴마다 자동, push 는 세션 시작·끝. `1_수집` 의 원본 파일은 git 에 안 올라가니 따로 챙긴다.
- **긴 대화**: 맥락이 커질수록 한 마디가 비싸진다. 대화창 계기의 «맥락»을 본다.
- **튜토리얼**: 토큰을 쓰지 않는다. 대본의 답과 일은 연습이고, 튜토리얼 중에 직접 친 질문도 연습 단계에서는 연습 답이 나온다.
- **상자 고르기의 토큰**: 그림 = 가로×세로÷750 · 글자 = 영어 약 0.33/자, 한글 약 1.07/자. 그래서 작고 빽빽한 글은 그림이 더 쌀 수 있고, 칩이 더 싼 쪽으로 붙는다. 의심되면(수식 기호·첨자·글자 밖 선과 그림) 그림으로 둔다. 글자층이 없는 스캔·판서는 OCR 을 돌려 믿을 만할 때만 글자로 바꾸고, 끝나기 전에 보내면 그림으로 간다.
- **상자 고르기의 한계**: 옵시디언 본창 화면을 그대로 뜬다. 칩에 «작음»이 뜨면 글자가 작아 Claude 가 못 읽을 수 있으니 확대한 뒤 다시 고른다. 새 창(팝아웃) 안은 못 뜬다.

## 문제가 생기면

- 전체 상태: 명령 «외부뇌 건강 보기» · 상태 막대 ✓ △ ✗(`py -3 3_시스템/brain.py doctor`).
- 찾기가 이상하면: 홈 «찾기 색인» 또는 `py -3 3_시스템/search.py --rebuild`.
- 승인 창이 안 뜨는 것 같으면: `powershell -NoProfile -ExecutionPolicy Bypass -File 3_시스템/_eval/gate-verify.ps1` 끝 줄이 `mismatches = 0` 이면 정상이다.
- 전에 비슷한 문제가 있었는지: «예전에 비슷한 문제 어떻게 풀었지?» — `3_시스템/_ref/` 를 찾는다.
- 왜 이렇게 만들었는지: [[설계노트]].
