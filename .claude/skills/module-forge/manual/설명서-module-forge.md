# 모듈 점검

목차 = [[사용자설명서]]

module-forge 모듈이다. 모듈이 코어나 다른 모듈과 부딪히지 않는지 파일만 보고 검사한다. 모듈을 넣거나 고친 뒤 돌린다. 해 보기 = 튜토리얼 «모듈 점검».

## 찾아보기

| 하고 싶은 것 | 이렇게 | 해 보기 |
|---|---|---|
| 모듈 충돌 검사 | 행위 «모듈 충돌 검사(전 모듈)» · «모듈 충돌 검사해 줘» | 모듈 점검 |
| 이 모듈이 괜찮은지 | «이 모듈 괜찮나» · «경계 위반 확인» | 모듈 점검 |
| 모듈 튜토리얼 쓰기 | «이 모듈 튜토리얼 만들어 줘» — 검사 스킬의 «튜토리얼 만들기» 순서로 쓴다 | |

## 돌리기

- 행위: 홈 «행위 고르기» › «모듈 충돌 검사(전 모듈)». 토큰을 쓰지 않는다.
- 말로: «모듈 충돌 검사해 줘»(일 모드).
- 건강 줄: 모듈마다 «검사 통과» · «검사 경고 N» · «검사 막힘 N» 이 함께 나온다.

## 막힘과 경고

막힘은 고쳐야 한다.

- 이름: `_` 로 시작 · 코어 스킬과 같음 · 노트 이름 겹침.
- 자리: `1_수집` 침범 · 다른 모듈과 같은 자리를 씀 · 코어 설정 키 · 코어 파일을 대본에서 참조 · 읽기 선언(`reads`)에 `1_수집`·코어 파일.
- 훅: 세션 시작·끝·Stop 훅 등록.
- 의존: 순환 · 없는 모듈.
- 선언(`contributes`): 행위 id 접두 · 겹침 · 위험 등급 · 없는 대본 · 모듈 밖 화면 · 모듈 밖 튜토리얼·설명서 · 설명서 이름 겹침 · 코어 글이 모듈 설명서로 거는 링크.
- 튜토리얼(형식 v2): 해 보기가 절반 미만 · 해 보기 아닌 단계가 연달아 둘 · 첫 단계가 글 · 끝 확인·해낼 일·풀이 없음 · 말에 자리 낱말(자리는 테두리가 가리킨다) · 모르는 낱말 · 연습 선언과 쓰임이 다름. 옛 꼴(형식 v1) 장은 알리기만 한다(옛 장을 다 옮길 때까지).

경고는 통과하되 알린다: `module.json` 없음 · 선언과 실제가 다름 · 자리가 포함 관계 · 모듈 밖 대본 · 행위 이름 없음 · 대본의 경로가 선언(`touches`·`reads`) 밖 · `reads` 가 `touches` 안 · 튜토리얼의 긴 말·미리 채운 말·7단계 넘음.

런타임 충돌(훅 순서·포트)은 재지 못한다. Claude 가 스킬 글을 읽고 쓰는 경로도 추적하지 못한다.

## 모듈 만들 때

모듈은 `.claude/skills/<모듈>/` 폴더 하나다. `module.json` 의 `contributes` 로 자리를 선언하면 바탕이 알아서 보이고 치운다.

| 칸 | 뜻 |
|---|---|
| `actions` | 행위(id = `<모듈>.이름`) |
| `doctor` | 건강 한 줄 대본 |
| `record` | 세션 기록 때 부를 대본(낸 줄 = 고칠 것) |
| `view` | HTML 화면 한 장 |
| `tutorial` | 대본 폴더(형식 v2 · 토큰 0 · 코어 장 뒤에 이어짐) |
| `manual` | 설명서 장 `[{file, name, gist}]`(이름 = `설명서-<모듈>…` · `## 찾아보기` 표는 찾아보기 노트에 합쳐짐) |

코어 글에서 모듈 설명서로 위키링크를 걸지 않는다. 끄면 깨진다. 산출물은 `2_지식/modules/<모듈>/`, 파생은 `3_시스템/_index/<모듈>/`.

튜토리얼은 읽는 글이 아니라 해 보는 장이다. 해 보기가 절반을 넘고 끝에 혼자 한 번 해내는 «확인»이 있어야 검사를 통과한다. 쓰는 순서와 본보기는 검사 스킬의 «튜토리얼 만들기» 절(`.claude/skills/module-forge/skills/check/SKILL.md`)에 있다.

자리 선언은 둘로 가른다. 모듈이 쓰는 자리는 `touches`, 읽기만 하는 남의 자리(코어 엔진 상태 폴더·설정 노트)는 `reads` 에 적는다. 남의 자리를 `touches` 에 넣으면 주인을 잘못 선언하게 된다.

## 끄면

검사 스킬·행위·이 장·튜토리얼이 사라지고, 다른 모듈의 건강 줄은 «정적 검사 없음»이 된다. 막히는 코어 기능은 없다. 대신 모듈이 부딪혀도 건강 줄로는 모르니, 모듈을 넣거나 고칠 때는 켜 둔다.
