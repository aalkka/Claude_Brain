# /module-forge:check <모듈명> — 정적 충돌검사 (가드레일)

신규·기존 모듈이 코어·다른 모듈과 부딪히지 않는지 정적으로 검사. 런타임 충돌(훅 실행순서·MCP 포트·`bin/` PATH)은 **범위 밖**(정직 — P4 연기).

## 실행
```bash
py -3 "${CLAUDE_PLUGIN_ROOT}/scripts/check.py" <모듈명>
```
| 형태 | 용도 |
|---|---|
| `check.py <모듈명>` | 단일 모듈 검사 |
| `check.py --all` | 전 모듈 일괄(하나라도 block이면 exit 1) |
| `check.py <모듈명> --sync-surfaces` | `surfaces` 선언을 실제 스캔값으로 갱신 후 재검사 |
| `check.py <모듈명> --no-registry` | 레지스트리 재생성 생략(테스트용) |

출력 = `{"ok": bool, "blocks": [...], "warns": [...], "infos": [...]}`. **block 있으면 exit≠0.**
부산물 = `3_시스템/_index/modules.json` 레지스트리 재생성(gitignore=파생·재생성).

## 검사 항목 (P3② 완결 — 전종 실동작)

**block — 통과 불가**
| # | 검사 | 근거 |
|---|---|---|
| 1 | `_` 접두 모듈명 | 로더 스킵(P0 실측) — kebab 필수 |
| 2 | 모듈명 ↔ 코어 plain 스킬 동명 | 루트 SKILL.md가 plain 스킬 `<모듈>`로 등록 → 전역 오염 |
| 3 | 노트 basename 중복 | 위키링크 `[[name]]` 모호 ([[설계노트]] §12.6 로직 재활용) |
| 4 | `1_수집/**` 침범 (touches·reads·스크립트 리터럴) | **I3** 사용자 저작물 불가침(읽기 선언으로도 못 풂) |
| 5 | 예약훅 등록 (`Stop`/`SessionStart`/`SessionEnd`) | **I2** 코어 결정론·커밋 durability |
| 6 | 모듈간 `touches` **동일경로** | 소유권 모호 = 경계 붕괴 |
| 7 | `dependencies` 순환(DFS)·미존재 | 단방향 의존 강제 |
| 8 | `writes_config` 비어있지 않음 | **I3** 코어 config 불가침(A6 = config 모듈별 격리) |
| 9 | 스크립트가 코어파일 참조 (`3_시스템/config.json`·`hooks/`·`search.py`·`.claude/settings.json`·`CLAUDE.md`·`.gitignore`) · `reads` 가 코어파일에 닿음(그것을 품은 넓은 폴더 포함) · `reads` 가 경로 목록 아님 | **I1** 코어 무수정 — `reads` 로 코어파일을 풀지 않는다 |
| 10 | 산출물 폴더 규약 위반 — 역할 `notes` 자리 선언(코어 지식 전용) · `modules/` 루트 독점 · **타모듈 폴더 침범** | 모든 모듈이 `2_지식/modules/<모듈명>/`로 동일 형식 |
| 11 | `contributes` 행위·건강 선언 — 행위 id 가 `<모듈>.` 로 시작 안 함 · 코어·다른 모듈·같은 모듈과 id 겹침 · `risk` 가 read·write·send·usage 밖 · `builtin` · 명령줄이 문자열 목록 아님 · 대본 없음 · `args` 에 없는 자리표 | 코어 `brain.py` 가 읽는 계약(ADR-019) — 겹치면 먼저 읽은 것만 쓰여 조용히 사라진다 |
| 12 | `contributes` 튜토리얼·설명서 선언 — 모듈 밖 경로 · 대본 없음 · 장 번호 겹침 · **형식 v2 장의 합격선 미달**(`3_시스템/tutorial_lint.py` 와 같은 함수 — 해 보기 절반 미만·연달아 둘·첫 단계 글 · 풀이·끝 확인·해낼 일 없음 · 자리 낱말 · 모르는 동사·자리·data-tt · 연습 선언 불일치 · `연습: 모듈` 인데 화면 선언에 `practice` 없음 · 보낼 말을 `넣기:` 없이 치게 함·`시킬 말:` · 진짜에 닿음(`행위` 동사 · 연습 파일 밖 `치우기`·`되살리기` · `받은함치우기`) · 행위 고르기에서 고른 행위에 `연습: 행위` 흉내 없음 · 끝 확인이 앞 단계를 그대로 되풀이(같은 대상)) · 형식 v1 장(머리에 `형식: 2` 없음 = 미달 «형식 v1» · 13장 모두 v2 11-08 · 엔진이 못 읽는 꼴 `장:` 숫자·`이름:`·단계마다 `말:`·`연습 파일:` 도 함께) · 설명서 이름이 `설명서-<모듈>` 로 시작 안 함 · 볼트·코어 장·다른 모듈 장과 이름 겹침 · `name`·프론트매터 없음 · **코어 글이 모듈 장으로 링크** | 켜진 모듈 것만 볼트 목록에 합쳐지고 끄면 사라진다(ADR-035) — 코어 글에 링크가 있으면 끌 때 깨진다. 형식 v1 장은 합격선 미달을 info 로만 알린다(13장을 v2 로 옮길 때까지). 미달·대본 없음이면 안내 줄(info)이 아래 «튜토리얼 만들기» 를 가리킨다 |

**warn — 통과하되 알림**
| 검사 | 뜻 |
|---|---|
| `module.json` 부재 | 볼트 쓰기경계 미선언 → 검사 대부분이 무음 통과 |
| `surfaces` 드리프트 | 선언 ↔ 실제 스캔 불일치(스킬 추가 후 미갱신). `--sync-surfaces`로 해소 |
| `touches` 포함관계 | 상위 경로 모듈이 하위를 덮음 → 경계 좁힐 것 |
| 스크립트 경로가 `touches`·`reads` 밖 | 선언 밖 접근 — 쓰면 `touches`, 읽기만 하면 `reads` 에 |
| `reads` 가 `touches` 안 | 중복 — 쓰는 자리는 `touches` 하나로(읽기도 덮음) |
| 무관 basename 중복 | 이 모듈과 무관한 기존 중복(볼트 청소 권고) |
| `schema` 상회 | `module.json`이 이 검사기보다 새 스키마 → 검사기 갱신 필요(미지원 필드 무시 중) |
| 행위·doctor 가 모듈 밖 대본 | 모듈을 빼거나 옮기면 깨짐 → 모듈 안 `scripts/` 로 |
| 행위 `name` 없음 | 목록·옵시디언에 id 가 그대로 보임 |
| 설명서가 다른 모듈의 장으로 링크 | 그 모듈을 끄면 깨진다 |
| 형식 v2 튜토리얼 대본의 경고 | 긴 말 · 손으로 쓴 `정리:` · 7단계 넘음 · 고르기창 줄을 안 고르는 `연습: 행위` · 쓰지 않는 연습 선언 |

**infos** — 네임스페이스 열거(네이티브 `/<모듈>:<스킬>`가 이미 충돌차단 → 정보만) · 루트 SKILL.md의 plain 등록 · 훅 보유 시 런타임 한계 고지.

## touches 와 reads (`module.json`)
- `touches` = 이 모듈이 쓰는(소유하는) 볼트 경로. 모듈 간 겹침(6)과 `brain.py` 모듈 디스크 크기의 근거.
- `reads` = 읽기만 하는 남의 볼트 경로(코어 엔진 상태 폴더·설정 노트 등 — 주인은 코어나 다른 모듈). 남의 자리를 `touches` 에 넣으면 주인을 잘못 선언하고 그 크기까지 모듈 몫으로 센다. 대본 리터럴이 `touches ∪ reads` 안이면 경고하지 않는다.
- `reads` 의 위 폴더 안에 내가 쓰는 칸이 있는 것은 정상이다(예: reads `3_시스템/_index/collect/` · touches `3_시스템/_index/collect/draft/`).

## forward-compat (P4 도입 대비)
`module.json`의 **모르는 키는 무시**한다 → 미래 필드를 미리 넣어도 검사기가 안 깨진다. 예약어 = `runtime`(MCP 포트·`bin/` PATH) · `router`(라우터 노출제어) · `marketplace`(배포 메타). 스키마 변경 시 `schema` 값을 올리면 **구버전 검사기가 warn으로 자백**한다. 더한 키(`contributes`·`reads`)는 `schema` 1 그대로다 — 구버전은 `reads` 를 무시해 «touches 밖» 경고를 낼 뿐이라(더 엄격 · 거짓 통과 없음) 올릴 까닭이 없다. 올리는 것은 있던 키의 뜻이 바뀌어 구버전이 거짓 통과할 때다. 출력 계약(`ok`/`blocks`/`warns`/`infos`)은 **키 추가만 허용·기존 키 의미 불변**.

## block 시 조치
- **basename 중복** → 노트/모듈명을 고유 basename으로 개명.
- **1_수집 침범** → `touches`·스크립트에서 제거. 사용자 저작물은 불가침(승격만).
- **예약훅** → `hooks.json`을 안전 이벤트(`PostToolUse`·`PreToolUse`·`UserPromptSubmit` 등)로 교체.
- **touches 동일경로** → 한쪽을 하위 경로로 좁히거나 소유 모듈을 정한다.
- **deps 순환** → 공통부를 제3 모듈로 빼거나 의존 방향을 하나 끊는다.
- **튜토리얼 대본(⑫)** → 까닭은 `py -3 3_시스템/tutorial_lint.py --why <대본>`. 아래 «튜토리얼 만들기» 순서로 글 카드를 해 보기로 바꾼다. 규칙만 맞춘 해 보기(들어갈 때 이미 참 · 쓸모없는 동작)는 정적 검사가 다 못 잡는다 — 재생기와 단계 그림 띠로 본다.

## 튜토리얼 만들기 (모듈 장 · 형식 v2)

튜토리얼은 읽는 글이 아니다. 사용자가 화면에서 직접 해 보고, 끝에 혼자 한 번 해내는 장이다. 직접 해 보기도 흉내다 — 토큰 0 · 볼트 영향 0(장이 끝나거나 끊긴 뒤 볼트가 시작 전과 같음 · 연습 파일이 `0_작업/튜토리얼` 에 잠깐 생겼다 사라지는 것만 허용 · 사용자 11-09). 모듈을 만들거나 고칠 때 대본을 쓰기 전에 이 순서를 밟는다. 세션 끝에 남은 맥락으로 쓰지 않는다. 까닭(11-07 잼): 11-04·11-05 모듈 장 6개가 글 카드만 이어 «재생됨»으로 통과했고(32단계 중 글 59% · 끝 확인 0), 그 장들이 본보기 노릇을 해 같은 꼴이 번졌다.

1. **해낼 일** — 머리 `없애는 일`(이 모듈이 없애는 반복 일)에서 `해낼 일` 한 줄을 뽑는다. 장을 끝낸 사람이 혼자 하는 일이고, 끝 `## 확인` 단계가 그것을 가리킴 없이 한 번 시킨다. 확인은 앞 단계를 그대로 되풀이하지 않는다(같은 대상 · 미리 채운 말 보내기만 = 검사가 막음) — 앞에서 말로만 배운 일이나 다른 대상을 찾아 하는 일로.
2. **해 보기 2~5개** — 대본을 쓰기 전에 단계마다 셋을 정한다.
   - 자리: 엔진 자리(`리본`·`홈`·`창`·`입력` … · 목록은 `py -3 3_시스템/tutorial_lint.py --vocab`) 또는 모듈 화면 안 `화면 "<이름>"`(화면 HTML 에 `data-tt="<이름>"` 을 단다 · 화면 문).
   - 사건: 사람의 동작 — `보임`·`사라짐`·`늘어남`·`연파일`·`열림`·`있음`·`없음`·`받은함`·`화면 누름|바뀜|보임 "<이름>"`. 글 카드(`기다리기: 다음`)는 해 보기 사이에 하나까지 · 첫 단계는 해 보기.
   - 연습 상태: 그 단계가 서려면 있어야 하는 것(연습 파일 · 모듈 연습 자료 · 꼴).
   - 행위(`contributes.actions`)는 사람 길로 고르게 하고(`가리키기: 고르기창 "<행위 이름>" 또는 홈 "행위 고르기"` · 풀이 `누르기 홈 "행위 고르기"` + `누르기 고르기창 "<행위 이름>"`) 같은 단계에 `연습: 행위 | <행위 id> | <결과 글>` 을 단다 — 튜토리얼이 도는 동안 엔진은 진짜 행위를 돌리지 않고 결과 창에 그 글을 띄운다(실행 기록·장부 0). `행위 <id>` 동사(바로 돌림)는 검사가 막는다. 휴지통·장부·받은함 정리도 흉내다(엔진의 연습 휴지통·흉내 장부 · `휴지통에두기`·`이름바꾸기`). 받은함 연습만은 진짜 받은함을 쓴다 — 연습 파일이 진짜 받은함에 들어오고 «옮기기»는 엔진이 그 파일을 바로 지우는 흉내다(장부·휴지통 0 · brain-base 0.46.4).
   - 보낼 말: Claude 에게 보낼 말은 사람이 치지 않는다(사용자 11-08). `넣기: <보낼 말>` 을 쓰면 엔진이 그 단계에 들어갈 때 입력칸에 채우고, 사람은 고쳐도 되고 전송만 누른다(해 보기로 셈). 풀이는 인자 없는 `보내기`(채운 말 그대로 전송). `말:` 에 치게·적게·복사·붙여넣게 하는 지시를 쓰지 않는다 — «…가 채워져 있으니 보내 보세요». `시킬 말:` 은 쓰지 않는다(검사가 막음). 모듈 화면 칸에 칠 말(예: 수집 창 뺄 말)도 같다 — `보여 주기: 채우기 화면 "<이름>" <말>` 로 채우고 사람은 Enter 만(풀이 `치기 화면 "<이름>" <말>`).
3. **연습** — 장이 만들거나 바꾸는 것은 머리 `연습:` 에 선언한 것뿐이다. 엔진이 연습 장부에 먼저 적고 장 끝·그만·창 닫기·강제 종료 뒤 다시 켤 때 치운다(대본에 `정리:` 를 쓰지 않는다). 화면이 있는 모듈은 `연습: 모듈` 과 `contributes.view.practice`(연습 자료 명령 · `["{py}", "<대본>", "view", "--practice", "--acts", "{acts}"]`)를 둔다. 대본은 진짜 `view()` 와 같은 그리기로 연습 자료를 그리고, 그 장 동안 화면의 쓰기는 흉내로만 반영된다(진짜 대본 0). 연습 자료 id 는 `연습-` 으로 시작하게 하고, 진짜 쓰기 명령이 그 id 를 거부하게 한다.
4. **대본 · 검사 · 재생** — 해 보기마다 `풀이:`(엔진이 대신 하는 그 동작 — 건너뛰기·이어서·재생이 이 줄로 넘는다)를 단다. `py -3 3_시스템/tutorial_lint.py --why <대본>` 막음 0 → `check.py <모듈>` ⑫ 막음 0 → 재생기(`C:\brain-base\test\tutorial_replay.mjs` · brain-base 폴더에서 `node test/tutorial_replay.mjs [--states 기본,빈,곁창]` · 장은 진짜 볼트에서 읽는다 · 격리 옵시디언 하나씩)에서 들어갈 때 거짓 → 풀이 → 참 · 단계마다 끊어도 잔여 0.
5. **그림으로 보고** — 재생기가 남긴 단계 그림 띠를 보고에 붙인다. 보스·사용자는 글이 아니라 화면으로 판단한다.

본보기 — 새 장은 이 둘을 본뜬다. 형식 v1 장(머리에 `형식: 2` 가 없음)은 본뜨지 않는다.

## 정직한 한계 (범위 밖)
- **런타임 충돌** 미검출: 훅 실행순서·MCP 포트·`bin/` PATH — P4 연기.
- **Claude 세션 쓰기는 정적 귀속 불가**: SKILL.md 프로즈를 읽고 Claude가 쓰는 경로는 추적 못 한다. `touches` 준수 검증은 **모듈 스크립트(결정론 코드)** 범위만.
- 리터럴 스캔은 '언급'과 '접근'을 구분 못 함 → 주석·글로브(`*`)는 제외, 필요 시 줄에 `mf:allow-path`(줄 제외)·파일 상단 40줄 내 `mf:allow-path-file`(파일 제외) 표식.
- 같은 까닭으로 읽기·쓰기도 못 가른다 — `reads` 는 선언일 뿐, 그 자리에 쓰는 대본을 못 잡는다. 따옴표 안의 `2_지식/…`·`3_시스템/…` 꼴만 보므로 `os.path.join(SYS, '_index', …)` 처럼 조립한 경로도 못 본다 → `reads` 는 좁게(폴더·파일 하나씩).
