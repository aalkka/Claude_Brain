# 업데이트

목차 = [[사용자설명서]]

dist-sync 모듈이다. 배포판의 새 판을 이 볼트로 들이고, 제작자는 이 볼트의 코어를 배포판으로 보낸다. 파일을 코어·씨앗·개인 층으로 갈라 개인 노트·수집물은 열지 않는다. 해 보기 = 튜토리얼 «업데이트».

| 배포판에 올리기 | «배포판에 올려» · «배포판 적용»(제작자 · 일 모드) | |
| 배포판에 안 올린 것 보기 | 건강 줄 «모듈 dist-sync» · 자세히 = `dist-check.py`(제작자) | |
| 이 PC 에 더 설치·설정할 것 보기 | «바깥 설정 점검» · 건강 줄 «볼트 밖 설정 안 됨» | |

## 받기

«업데이트 있어?» · «최신 배포판 받아줘»(일 모드).

1. 진단: 볼트를 고치지 않고 할 일을 보여 준다 — 바뀔 코어 · 내 수정과 합칠 파일 · 못 합친 파일 · 배포판이 뺀 파일.
2. 승인 한 번: 옵시디언을 닫고 적용한다. 코어 게이트가 한 번 묻는다.
3. 되돌리기: 옛 판은 휴지통으로 가고 장부에 묶음 하나로 남는다. 홈 «관리» › 장부.

| 이 볼트의 파일 | 하는 일 |
|---|---|
| 없음 | 새로 넣음 |
| 과거 판과 같음(안 고침) | 새 판으로 바꿈 |
| 과거 판과 다름(내가 고침) | 합침 · 못 합치면 그대로 두고 알림 |
| 배포판이 뺐음 | 안 고쳤으면 휴지통 · 고쳤으면 남기고 알림 |
| 내가 만든 파일 | 손대지 않음 |

MOC·recent·open-loops 같은 씨앗 파일은 덮지 않는다. `git pull` 을 쓰지 않는 까닭이다: 매일 쓰는 파일이 함께 추적되어 충돌로 멈춘다.

## 보내기(제작자)

«배포판에 올려» · «배포판 적용»(일 모드). 진단 → 익명화 문구 쓰기 → 옮기기 → 검증 → 커밋까지 하고 push 는 따로 승인받는다. 치환은 기계로 하지 않고 후보만 찾는다.

## 건강 줄

«모듈 dist-sync» 줄에 원격 주소와 마지막으로 받아 둔 판의 날짜가 보인다. 네트워크는 쓰지 않는다. 원격이 없으면 △ 이고, 받기 스킬이 처음에 더한다.

제작자 볼트(배포판 worktree 가 있음)에서는 이 줄이 **배포판 최신 점검**이 된다. 어긋나면 △ 와 함께 «배포판 어긋남 N — 안 올린 고침 · push 안 함 · 받을 것 · 할 일» 한 줄이 뜨고, 없으면 «배포판 최신»이다. 홈 머리·상태 막대의 △ 를 누르면 보인다.

| 칸 | 뜻 | 할 일 |
|---|---|---|
| 안 올린 고침 | 볼트에서 고쳤는데 배포판에 안 간 코어(배포판이 그 파일을 마지막으로 고친 뒤에 고친 것 · 새 코어 · 지운 코어 · 층 미정 새 파일) | «배포판 적용» |
| 커밋 안 함 | 배포판 worktree 에 커밋 안 한 고침 | 배포판 커밋 |
| push 안 함 | 배포판에 커밋했는데 원격에 안 올린 것 | push 승인 |
| 받을 것 | 원격에만 있는 커밋 | 배포판 worktree 에 받아 합치기 |

- 재는 때: 건강 줄이 잴 때(옵시디언 30분마다)마다. 점검은 6시간 담아 두고, 배포판 커밋·원격·받기가 바뀌면 바로 다시 잰다. 원격 받기(`git fetch`)는 하루 한 번 창 없이 따로 돈다 — 원격을 보는 것은 이것뿐이다.
- 배포판이 익명화해서 늘 다른 파일은 볼트를 다시 고치기 전엔 안 잡힌다.
- 일부러 안 싣는 고침: `py -3 .claude/skills/dist-sync/scripts/dist-check.py --ack <경로>` — 그 파일을 다시 고치면 다시 잡힌다.
- 자세히: `py -3 .claude/skills/dist-sync/scripts/dist-check.py [--fetch]` — 파일·커밋 목록. 점검은 읽기와 받기만 한다(커밋·push 안 함).
- ④ «안내 없는 바깥 설정»: 배포판·볼트 코어가 볼트 밖(작업 스케줄러·레지스트리·브라우저·설치·git 설정 등)을 건드리는데 아래 목록에 없는 곳. 목록에 항목을 더하면 사라진다.

## 볼트 밖 설정

볼트는 PC 의 몇 가지에 기댄다 — 파이썬과 꾸러미 · Git for Windows · git 이름·훅 · Claude 로그인·폴더 신뢰 · 옵시디언과 제한 모드 끄기 · (선택) 옵시디언 CLI · 한국어 OCR · Word · 크롬 · defuddle · GPU 검색. 목록은 이 모듈의 `external.json` 이고 항목마다 확인 명령 · Claude 가 할 명령 · 사람 단계가 있다.

- «바깥 설정 점검»: Claude 가 이 PC 를 재서, 할 수 있는 것은 묻고 대신 하고, 사람이 해야 하는 것(앱 화면·로그인·관리자 권한)은 한 단계씩 안내하고 다시 잰다.
- 건강 줄: 필수 항목이 안 됐으면 «볼트 밖 설정 안 됨 N» 이 뜬다. 하루 한 번 창 없이 따로 잰다.
- 업데이트 끝에도 한 번 잰다(새 판이 설정을 더했을 수 있다).
- 이 판에서 켤 수 없는 것: 받는 문(탐색기 우클릭·Ctrl+Alt+B) — 실행 파일이 배포판에 없다.

## 끄면

받기·보내기 스킬 · 건강 줄 · 이 장 · 튜토리얼이 사라진다. 볼트의 다른 기능은 그대로 돈다. 대신 새 판을 받을 길이 없으니 업데이트할 때 다시 켠다. 판 해시 표와 지난 진단 기록은 그대로 남는다.
