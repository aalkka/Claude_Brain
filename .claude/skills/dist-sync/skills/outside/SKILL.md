# /dist-sync:outside — 볼트 밖 설정 점검·안내

목록 = 이 모듈의 `external.json`(항목마다 확인 명령·Claude 가 할 명령·사람 단계). 재는 것은 대본이 하고, Claude 는 묻고 안내한다.

## 1. 잰다

```bash
py -3 .claude/skills/dist-sync/scripts/external.py check
```

이 볼트에 그 기능의 파일이 있는 항목만 나온다. ✓ 됨 · ✗ 안 됨 · ? 명령으로 못 재는 것(화면 확인).

## 2. 안 된 것을 순서대로 — 필수 먼저, 선택은 쓸지 먼저 묻는다

- **«Claude 가 할 수 있음» 칸이 있는 것**: 무엇을 왜 하는지 한 줄로 말하고 **승인을 받은 뒤** 그 명령을 돌린다. 프로그램 설치(winget)·꾸러미 설치는 내려받기라 꼭 묻는다. 이름·메일·주소처럼 사람만 아는 값은 물어서 넣는다.
- **사람 단계만 있는 것**: 처음 쓰는 사람이라고 보고 안내한다.
  - **한 번에 한 단계만** 말한다. 단계 글을 그대로 읽어 주되, 어디를 누르는지(메뉴 이름·단추 글자)를 빼지 않는다.
  - 사람이 «했어요» 하면 확인 명령으로 다시 잰다(`external.py check` · 화면 확인 항목은 그 말대로 물어본다). 안 됐으면 무엇이 보이는지 물어 그 화면에서 다음 동작을 알려 준다.
  - 화면 글자가 영어면 괄호 안 영어 이름으로 찾게 한다.
- 설치 뒤 «창을 닫았다 다시 열기» 가 든 항목은 Claude 창도 다시 열어야 하니, 남은 항목을 먼저 말해 두고 그 단계를 맨 뒤로 미룬다.

## 3. 끝

다시 재서 남은 것을 한 줄로 알린다(되는 것 N · 남은 것 · 왜 남겼는지). 건강 줄은 하루 한 번 다시 잰다.

## 목록을 고칠 때(제작자)

새 코어가 볼트 밖을 건드리면(작업 스케줄러·레지스트리·브라우저·설치·git 설정 등) `dist-check.py` ④ «안내 없는 바깥 설정»과 `external.py scan` 에 잡힌다. 항목을 더한다 — 확인(종료 0 = 됨, 읽기만, 무거운 꾸러미는 불러오지 않음) · 하기(Claude 명령) 또는 안내(사람 단계 2개 이상 · 메뉴 이름과 단추 글자) · 쓰는 곳 · 종류. 확인 명령은 «안 된» 상태와 «된» 상태에서 각각 돌려 0·1 이 갈리는지 잰다.

## 하지 않는 것

- 승인 없이 설치·설정을 바꾸지 않는다. 관리자 권한·보안 설정·로그인·비밀번호 입력은 사람이 한다.
- 단계를 한꺼번에 쏟아 놓지 않는다.
