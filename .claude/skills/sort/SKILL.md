# sort — 분류 · 태그 · 알림

설계 = 제작자 설계 노트(배포판에 없음)(§2 경계 · §4 규칙 꼴 · §7 알림) · 사람 꼴 = `3_시스템/설명서/설명서-분류와-알림.md`.

## 세 도구의 경계
- **분류 `3_시스템/sort.py`** = 결정만. 대상 × 체계 → 갈래 + 근거 + 판정자 + 급함. 체계 파일 = `3_시스템/sort/<체계>.json`(꼴 = `sort.py` 머리말 · 예 = `3_시스템/sort-examples/항공권-티어.json`). 갈래의 «동작»(태그·알림·들이기·장부)은 넘김 장부 `_index/sort/넘김.jsonl` 로 넘긴다.
- **태그 `3_시스템/tag.py`** = 붙이기만. 수집글·가격줄 = 겹쳐 보이기(1_수집 원본은 안 고침 · 읽는 쪽이 `tag.has`) · 0_작업·2_지식 노트 = 체계 `"노트에 쓰기": true` 일 때만 프론트매터(도구가 붙인 것만 뗌). 사전 = `3_시스템/sort/태그/사전.json`(뜻 · 순서 · 가족).
- **알림 = mobility 모듈 `.claude/skills/mobility/scripts/alert.py`**(사용자 11-18 «알림도구를 mobility 주관으로, 나머지는 본체») = 때·중복·전달만. 때 = `바로` · `아침` · `묶음 HH:MM` · 잘 시간이면 아침(급함이면 지금) · 같은 대상·같은 갈래 한 번 · 오르면 다시. 전달 = mobility 사건 kind `sort` + 즉시(서버 `/v1/push` · 시험판) + 알림 장부.
  본체는 판정·넘김 장부(알림 «동작»)까지 — mobility 가 꺼졌거나 없으면 알림 도구는 안 돌고, 수집 창 «일어난 일»은 넘김 장부의 알림 줄을 직접 보인다.
- 분류 run 이 알림 동작을 넘기면 그 자리에서 알림 도구를 부른다(`sort.alert_now` · mobility 켬일 때만). 15분 확인 끝(`collect-tick.py` act_tick)이 `tag.py tick` · (mobility 켬이면) `alert.py tick` 을 그물로 부른다.

## 규칙을 말할 때(«~면 태그 붙여» · «~면 알려 줘»)
1. 어느 체계인가 — 있는 체계면 그 파일 · 없으면 새 체계(대상 종류 = 수집글·가격줄 · 다른 대상은 어댑터부터 · 범위 밖이면 말하고 멈춤).
2. 체계 폴더를 스크래치패드로 복사해 사본만 고친다. 규칙마다 **«말» = 사용자 말 원문 그대로** · `만든이: "사용자 MM-DD"` · 기계 꼴(조건 낱말 13 · 표 · 함수). 동작은 갈래에: `{"태그": "<이름>"}` · `{"알림": {"때": "바로", "급함": false}}`(급함 true 는 밤에도 울려야 할 때만 — 사용자가 말할 때).
3. `py -3 3_시스템/sort.py check --dir <사본>` → 오류 0. 새 태그면 사본의 `태그/사전.json` 에 뜻(·가족)을 더하고 `tag.py list` 문제 0(진짜에 옮긴 뒤 다시).
4. `py -3 3_시스템/sort.py preview --dir <사본>` → **바뀌는 대상 목록을 그대로 보인다**(지금 판정에서 갈래가 바뀌는 것). 바뀌는 것이 있으면 보이고 확인받은 뒤 적는다 · 0 이면 그 말을 하고 적는다.
5. 진짜 파일에 Edit(사본을 덮어쓰지 말고 바뀐 줄만) → `sort.py check` → `sort.py run --system <체계>`(사용량 0) → 바로 보이게 하려면 `tag.py sync` · `py -3 .claude/skills/mobility/scripts/alert.py run`(분류 run 이 이미 불렀으면 할 일 없음).
6. 알림 규칙이면 폰에 실제로 울린다(mobility 켬). 시험은 사본으로만 — 진짜 알림을 시험 삼아 보내지 않는다.

## 사람 태그 · 지금 알림
- «이거 <태그>»: `py -3 3_시스템/brain.py run tag.apply target=<대상 id> tag=<태그>`(«아님» = `-- --off` · 근거 = `--why <말>`) — 그 체계에 판정자 «사람» 판정을 적고 겹쳐 보이기를 다시 그린다. 대상 id = `collect:<출처>:<글번호>`(수집글) · 대상 밖이면 거절된다.
- «지금 알려 줘»(대화 Claude 가 하나): `brain.py run mobility.alert_now title=<제목> -- --text <글> [--urgent]`(mobility 행위) — **진짜 폰에 간다**. 사용자가 알림을 바랄 때만 · 급함은 밤에도 울려야 할 때만. mobility 모듈이 없으면(배포판 기본) 폰 알림이 없다고 말하고 멈춘다.
- 보기: `brain.py run tag.list` · `brain.py run mobility.alert_list`(mobility 있을 때) · `py -3 3_시스템/tag.py has <대상> <태그>`.

## 태그의 칠(노트·일정 줄에서 보이는 꼴)
- 태그 사전(`3_시스템/sort/태그/사전.json`)의 그 태그에 «칠» 칸을 적는다: `{"바탕": "<CSS background>", "글": "<글자색>", "굵기": 700, "테": "<CSS border>", "알약": true}`(있는 칸만 씀).
- `py -3 3_시스템/brain.py run tag.paint`(먼저 `-- --dry`) → 옵시디언 CSS 스니펫 `<태그>.css` 를 만들고 켠다. 손으로 만든 같은 이름 파일은 규칙이 같으면 그대로 두고 다르면 안 건드린다(`--force` 는 사용자가 덮으라고 할 때만).
- 도구는 태그 이름을 모른다 — 어떤 태그를 어떻게 칠할지는 사전이 정한다. 색을 고를 때는 사용자에게 보이고 정한다(꼴 = `draft`).

## 개인화 파트(`personal/values.json` · 배포판에 안 실림)
- `황금 태그` — 공지 필터의 황금 태그(장학 가운데 통장으로 현금이 오고 막는 의무·소득 심사가 없는 글)를 이 볼트에서 부르는 이름. 그 이름 하나가 체계 파일(`3_시스템/sort/<이름>.json`)·태그·자격 카드의 칸·모아보기 칸(.moa `columns`)·일정 줄 `#<이름>` 에 같이 쓰인다 · 받는 곳 = 사용자에게 묻기(«현금 장학 표를 뭐라고 부를까요») · 없을 때 기본 = «황금».
- 이름을 바꾸면 위 다섯 자리의 옛 이름도 같이 바꿔야 한다(체계 파일 이름 · 사전의 태그 · 카드 칸 · .moa 칸 · 손으로 만든 스니펫) — 바꾸기 전에 목록을 보이고 확인받는다.
- 개인 태그와 그 칠은 사전(개인 층)에 있다. 설명서·시험·코드에는 개인 태그 이름을 적지 않는다.

## 판정 대기(④ Claude)
- 코드 규칙이 못 정한 것은 그 자리(수집글 = 출처)의 «판정 N» 에 쌓인다(`sort.py pending --place <자리>` = 건수·예상 사용량). 버튼(`sort.py judge --place <자리> --yes`)은 **사용량**이 든다 — 사용자가 수집 창에서 누른다. Claude 가 대신 누르지 않는다.

## 지킬 것
- 분류는 결정만 · 태그·알림은 동작만 — 태그 도구·알림 도구에 «붙일지·울릴지»를 넣지 않는다(체계 규칙으로).
- `1_수집` 원본은 고치지 않는다(태그는 겹쳐 보이기). 노트 쓰기는 기본 끔 — 켜는 것은 사용자 결정.
- 겉 동작 검사: `sort.py check` · `_eval/sort_check.py` · `_eval/sort_notice_golden.py`(py -3 · py -3.11) · 알림 쪽은 mobility 모듈의 시험.
