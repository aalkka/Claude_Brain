---
name: pdf-ingest
description: 원본 파일(PDF·docx·pptx·xlsx·hwp·html·txt)을 볼트 지식으로 — 1_수집에 두고 색인을 붙인다. PDF·문서 읽기 요청 시 통독 대신 이것.
---
**원칙(2026-10-14 개정 · ADR-013): 원본이 원천이다. 정리노트(원본의 열화판)를 기본으로 만들지 않는다.** 원본마다 **색인**(찾기용 · 쪽 링크)을 붙여 옵시디언 검색과 search.py 가 원문을 찾게 한다. 생략·축약·삭제 금지 원칙(07-04)은 색인에도 그대로다. 규칙 → `3_시스템/conventions.md` §원본·색인.

1. 원본을 `1_수집/<분류>/`에 둔다. 볼트 밖 파일은 **복사**해 들이고(밖의 원본은 그대로), 볼트 안 `받은함` 파일은 **이동**(볼트 안 복사 금지). 같은 sha256 이 이미 있으면 들이지 않고 보고.
2. `py -3 3_시스템/ingest.py <경로>` → `1_수집/_색인/<경로>.색인.md`. 출력의 품질을 본다 — «OCR N쪽» = 그림 쪽을 윈도우 내장 OCR 로 읽음(오독 있음 · 인용은 원본 쪽에서), «OCR 대기» = 엔진 실패(까닭이 붙음), «추출 실패» = 보고.
2-1. 그림 내용 읽기는 **사용자가 원할 때만**(Claude 사용량이 든다) — 옵시디언 색인 노트 머리 «그림 읽기» 단추, 또는 사용자가 «그림도 읽어줘» 하면 `py -3 3_시스템/ingest.py --vision <경로>`. Claude(claude -p · sonnet 5.5)가 그림마다 «무엇을 그렸나» 명사구 하나(+ 손글씨가 있으면 전사 · 글씨체 사전 `3_시스템/handwriting/`)를 색인에 덧붙인다. 대상 = 글자 없는 쪽 · PDF 그림 든 쪽 · docx·pptx·html 안 그림 · 그림 파일(한 번에 60장). 사용량 = 장당 약 430+40토큰(10장씩 한 번에 묻기 · 2026-10-26 실측) · 손글씨는 그 그림만 따로. 구독(claude.ai 로그인)이 아니면 묻지 않고 멈추고, 사용량 한도에 막히면 멈춘다. 이미 읽은 것은 다시 안 읽는다.
3. `py -3 3_시스템/search.py --reindex`.
4. 이후 질문 = `search.py` 경유 → 색인의 해당 쪽만 Read(`offset/limit`) → 그림·수식·표가 필요하면 원본 PDF 그 쪽만 Read(`pages`).
5. 정리노트는 사용자가 원할 때만 만들고 색인·원본 링크를 단다. 설계 근거 = [[학습노트-작성법-인지과학근거]]. 필기·판서 사진도 같은 길이다(2-1 손글씨 전사).

주의: 색인은 git 제외(원본에서 재생성). `3_시스템/_index/pdf-cache/` 는 원본이 볼트에 없는 옛 정제본만 남았다(물성전자) — 새로 만들지 않는다. 색인과 겹친 옛 정제본은 `pdf-cache-retired/` 에 있다(검색 대상 아님).
