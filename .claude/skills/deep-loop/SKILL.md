# deep-loop — 심화 조사 루프

`/deep-loop <N> <논점>`

**루프의 정의**: 각 루프의 질문은 앞 루프의 **답**에서 파생된다. 파생은 *다음에 무엇을 검색할지 정하는 것*이지 자기 답을 근거로 삼는 것이 아니다. 자료 유입이 루프가 작동하는 유일한 조건이다.

**조항을 고치기 전에 `references/rationale.md`를 연다.** 각 조항의 근거·실측·반대근거가 거기 있다. 근거 없이 고치면 같은 실수를 되풀이한다.

## 0. 시작 — 앵커·루프 수·관점

**앵커** — 원 논점을 한 줄로 적어 화면에 남긴다. 매 루프 이탈 판정 기준.

**루프 종류** — 먼저 **반증자가 있는지** 가른다. 측정·실행 결과로 내 전제가 틀렸음이 드러날 수 있으면 **실행 루프**, 자료만 들어오면 **조사 루프**다. 전제를 뒤집는 것은 자료가 아니라 측정이다(F1).

**루프 수** — 조사 루프는 사실확인형 2~3, 개방형 9~10에서 정체하므로 그 선에서 끝내고 **사람 판정으로 넘긴다**(A1·F2). 실행 루프는 **잴 것이 남아 있는 한 계속한다** — 사용자가 N을 지정했으면 N을 채운다. 성격이 어긋나면 시작 시 1회 말한다.

**관점 3~4개** — 화려한 페르소나가 아니라 **평범하고 구체적인 위치**를 먼저 세운다. 예: 비용을 대는 쪽 / 운용하는 쪽 / 실패를 뒷수습하는 쪽 / 반대 결론을 이미 채택한 인접 분야. 각 루프가 하나를 취한다. **관점을 바꾸는 것이 반증 장치다** — "반대 자료를 찾아라"는 지시는 효과가 확인되지 않았다(A2).

## 1. 진행 형태 — 앞은 넓게, 뒤는 좁게

| 구간 | 검색 | 관점 |
|---|---|---|
| 전반 (1 ~ N/2) | 짧고 넓은 질의, 자료 4~6건 | 매 루프 교체 |
| 후반 (N/2 ~ N) | 좁고 구체적인 질의, 자료 2~3건 | 전반에서 갈린 축에 집중 |

## 2. 각 루프 절차

1. **관점 검색** — 이번 관점에서 파생 질문을 검색. 독립 질의는 한 메시지에 함께 낸다.
2. **통제 밖 값 하나** — 이번 루프에 **내가 고르지 않은 값**이 들어왔는가: 측정 결과 · 실행 출력 · 볼트 실측(`search`) · 사람 판정. 없으면 **"이번 루프는 사유다"라고 쓴다**(건너뛰지 않는다). 검색 자료는 내 질의의 답이라 여기 들지 않는다 — 전문을 읽어도 전제는 안 뒤집힌다(F1 실측). **문헌과 자기 실측이 어긋나는 지점이 최대 산출이다.** 어긋나면 단정하지 말고 무엇을 재보면 갈리는지 쓴다.
3. **정직 표기** — §4.
4. **파생** — `→ *다음 질문*` 한 줄. 앞 답의 **어느 부분**에서 나왔는지 드러나게.
5. **예측 등록** — §3. 이번 루프에서 결론이 하나 굳었다면 반드시.

논점이 둘로 갈리면 **분해**하고, 다른 루프가 같은 말을 하고 있으면 **병합**한다.

## 3. 예측 등록 — 오류를 잡는 유일한 장치

결론이 처음 굳는 지점에서 **한 줄** 적는다.

> **예측**: <결론>이 참이면, 아직 보지 않은 <대상>은 <값>일 것이다. **반증조건**: <무엇이 나오면 틀린 것인가>.

그리고 **다음 루프에서 실제로 재고 대조한다.** 빗나가면 결론을 다시 쓴다.

- **대상은 아직 안 본 데이터여야 한다.** 결론을 만든 데이터에 되대입하는 것은 검산일 뿐 반증이 아니다.
- **반증조건 없는 예측은 예측이 아니다.** 무엇이 나오면 틀린 것인지 못 적으면 그 결론은 아직 주장이 아니다.
- **빗나갈 수 있는 것을 건다.** 안전한 예측만 고르면 장치가 죽는다.

근거: 오류 감지는 예측오차로만 일어나고, 자기성찰형 점검은 사람에게도 실패했다(C2·C3). 이 장치는 실연 2회 중 1회 반증에 성공했다 — 검산으로는 잡히지 않는 종류였다.

## 4. 정직 표기 (하드규칙)

- **인용은 `[제목, ID](url)` 형식.** 제목 없이 번호만 쓰면 기계 대조가 원리적으로 불가능하다(B6).
- **실제로 연 것만 링크한다.** 검색 결과 요약만 본 것은 `[검색요약]`, 재인용은 `[재인용]`.
- **웹 읽기는 `defuddle` 경유**(`.md`이거나 defuddle 실패 시만 WebFetch). **토큰 절감이 아니라 날조 방지다** — PDF·장문을 WebFetch로 읽으면 제목에서 내용을 지어낸다(B5 실측).
- **읽지 않은 자료의 저자·식별번호·수치를 쓰지 않는다.** 검색·fetch 결과에 실제로 뜬 문자열만 옮긴다. 접지 상태에서도 URL 3~13%가 날조된다(A6). **형식이 출처를 요구한다는 이유로 없는 것을 만들지 않는다. 자료가 없으면 "자료 없음"이 정답이다.**
- 벤더 자체 수치는 `(벤더)` + 우리 조건 적용 여부를 따로. 단일 관측·방법 미공개는 `⚠`.
- 측정한 것 / 추정한 것 / 인용한 것을 구분한다.

## 5. 재주입

루프 중반(N/2 부근)과 이후 긴 구간마다, **앵커와 아래 다섯 줄을 다시 적는다.** 요약을 새로 생성하지 않는다 — 다시 적기만 한다.

⑴ 앵커 ⑵ 인용은 실제로 연 것만 ⑶ 웹 읽기는 defuddle ⑷ 등록한 예측과 대조 상태 ⑸ 종결 시 `verify-citations.sh`

이때 앵커 문장 자체로 검색 1건을 낸다(반복 정제가 원 질문에서 멀어지는 것을 되돌린다, A3).

근거와 반대효과 → C4. **접기(요약 생성)는 규약 자체를 지울 수 있어 재주입만 남겼다.**

## 6. 종결

1. 루프별 섹션 — `## 루프 N — 그 루프의 질문`
2. **인용 검증** — `scripts/verify-citations.sh <이 대화를 옮긴 파일 또는 -u urls.txt>` 를 실행하고 **결과 표를 출력에 붙인다.** 스크립트가 재는 것은 링크 생존과 표기명 대조까지다. **"그 자료가 그 주장을 실제로 하는가"는 직접 확인한다.**
3. `## 정직하게, 아직 모르는 것` — 번호 매김. 각 항목에 **⑴ 무엇을 하면 확정되는가 ⑵ 지금 자료로 닫을 수 있는가**. **닫을 수 있는 항목이 남아 있으면 종결하지 말고 루프를 계속한다.**
4. `**Sources**` — 링크 목록.

## 중단 조건 (승인 없이 멈춘다)

- **조사 루프 — 등록할 예측이 2루프 연속 없다** → 결론이 굳은 것이다. 멈추고 몇 루프까지 갔는지·남은 질문이 무엇인지 쓰고 **사람 판정으로 넘긴다.** 굳은 뒤에 더 도는 것은 이미 올라탄 궤적을 증폭할 뿐이다(F2). 자료는 언제나 들어오므로(B3) 자료 고갈은 신호가 되지 못한다.
- **실행 루프 — 잴 것이 남아 있으면 멈추지 않는다.** 이 군은 전제 뒤집힘 0회인 세션이 실측 0%다(F1). 멈추는 것은 측정이 고갈됐을 때뿐이고, 그때도 **무엇을 새로 재면 갈리는지** 먼저 쓴다.
- 앵커 2회 이탈 → 논점이 잘못 잡힌 것이므로 재설정을 제안한다.

## 하지 않는 것

- **조사 루프는 실행하지 않는다.** 조사·문안·설계 제안까지고, 파일 수정·설정 변경은 루프 밖 별도 승인이다. **실행 루프는 실행이 곧 반증자이므로 루프 안에서 잰다** — 단 되돌리기 어려운 것(커밋·푸시·삭제·외부 전송)은 여전히 루프 밖 승인이다(F3).
- **볼트에 저장하지 않는다**(사용자 확정 2026-08-03). 남길 가치가 있으면 사용자가 그때 지시한다.
- 자료 공백을 매끄러운 추론으로 메우지 않는다. 공백은 공백으로 남긴다.
- 출력에 `lean` §3(도구 나레이션·장식·로그 덤프·패딩) 금지는 그대로. **길이 압축만 적용하지 않는다** — 불확실성·반박·근거는 lean §1 예외다.
