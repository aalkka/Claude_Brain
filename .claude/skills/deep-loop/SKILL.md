# deep-loop — 심화 조사 루프

`/deep-loop <N> <논점>`

**루프의 정의**: 각 루프의 질문은 앞 루프의 **답**에서 파생된다. 여기서 파생은 *다음에 무엇을 검색할지 정하는 것*이지 자기 답을 근거로 삼는 것이 아니다. 자료 유입이 루프가 작동하는 유일한 조건이다.

각 절차 항목의 근거는 §7에 있다. 규칙만 남고 근거가 사라지면 나중에 고칠 수 없다.

## 0. 시작 — 앵커·루프 수·관점

**앵커** — 원 논점을 한 줄로 적어 화면에 남긴다. 매 루프 이탈 판정 기준. 사용자가 범위를 좁혔으면 그 문구를 포함한다.

**루프 수** — 논점 성격이 정한다. 사용자 지정이 있으면 따르되, 성격이 어긋나면 시작 시 1회 말한다.
- 답이 하나로 수렴하는 **사실 확인형** → 2~3루프. 그 이상은 이득이 없다(§7-①).
- 답이 열린 **개방형 조사** → 9~10루프에서 정체.

**관점 3~4개** — 논점을 볼 서로 다른 각도를 먼저 세운다. 화려한 인물 페르소나가 아니라 **평범하고 구체적인 위치**를 쓴다. 예: 비용을 대는 쪽 / 실제로 운용하는 쪽 / 실패했을 때 뒷수습하는 쪽 / 반대 결론을 이미 채택한 인접 분야. 각 루프가 이 중 하나를 취한다.

## 1. 진행 형태 — 앞은 넓게, 뒤는 좁게

| 구간 | 검색 | 관점 |
|---|---|---|
| 전반 (1 ~ N/2) | 짧고 넓은 질의, 자료 4~6건 | 매 루프 교체 |
| 후반 (N/2 ~ N) | 좁고 구체적인 질의, 자료 2~3건 | 전반에서 갈린 축에 집중 |

## 2. 각 루프 절차

1. **원 질의 검색을 매 루프 유지** — 앵커 문장 자체로도 1건 검색한다. 파생 질의만 쓰면 원 논점과 느슨하게만 관련된 것을 찾게 된다(§7-③).
2. **관점 검색** — 이번 루프의 관점에서 파생 질문을 검색. 독립 질의는 한 메시지에 함께 낸다. 웹 읽기는 `defuddle` 경유(`.md`이거나 defuddle 실패 시만 WebFetch).
3. **볼트 대조** — 논점에 관한 자기 데이터가 있으면 `search`로 꺼내 문헌과 나란히 놓는다. **문헌과 자기 실측이 어긋나는 지점이 최대 산출이다.** 어긋나면 어느 쪽이 맞는지 단정하지 말고 무엇을 재보면 갈리는지 쓴다.
4. **정직 표기** — §4.
5. **파생** — `→ *다음 질문*` 한 줄. 앞 답의 **어느 부분**에서 나왔는지 드러나게.

**관점을 바꾸는 것이 반증 장치다.** "반대 자료를 찾아라"는 명시적 지시는 효과가 확인되지 않았다(§7-②). 각도를 바꾸면 다른 자료가 실제로 들어온다.

## 3. 구조 재조직 — 순차 반복의 본래 역할

증거 수집은 폭이 한다(한 루프 안의 병렬 검색). 순차 반복이 고유하게 기여하는 것은 **모인 것의 재조직**이다(§7-⑦). 매 루프 끝에 필요한 것을 적용한다.

- **분해** — 뭉뚱그린 논점이 둘 이상으로 갈리면 나눈다
- **병합** — 다른 루프가 같은 말을 하고 있으면 합친다
- **갱신** — 앞 루프 결론이 새 자료로 흔들리면 **흔들렸다고 쓰고** 다시 쓴다. 매끄럽게 이어붙이지 않는다

## 4. 정직 표기 (하드규칙)

- **인용은 실제로 연 것만.** fetch에 성공한 자료만 링크한다. 검색 결과 요약만 본 것은 `[검색요약]`, 원문 대신 재인용한 것은 `[재인용]`.
- **읽지 않은 자료의 저자·식별번호·수치를 쓰지 않는다.** arXiv 번호를 기억에서 적는 것은 금지 — 검색·fetch 결과에 실제로 뜬 문자열만 옮긴다.
- 검색에 접지된 상태에서도 URL의 3~13%가 날조된다(§7-⑥). **형식이 출처를 요구한다는 이유로 없는 것을 만들지 않는다. 자료가 없으면 "자료 없음"이 정답이다.**
- 벤더 자체 수치는 `(벤더)` 표시 + 우리 조건 적용 여부를 따로 쓴다.
- 단일 관측·방법 미공개 자료는 `⚠` + "방법 미공개" 명시.
- 측정한 것 / 추정한 것 / 인용한 것을 구분한다.

## 5. 컨텍스트 접기

**N/2 지점에서 앞 루프들을 요약으로 접는다.** 루프당 3~5줄 — 질문·핵심 수치·파생만 남기고 원자료 인용문은 버린다(출처 링크는 유지).

근거: 다중 턴 누적은 단일 턴 대비 평균 39% 성능 하락(§7-⑤). **접지 않으면 후반 루프가 앞 루프보다 나쁜 조건에서 판단하고, 깊이가 오히려 손해가 된다.**

## 6. 종결

1. 루프별 섹션 — `## 루프 N — 그 루프의 질문`
2. **인용 검증 패스** — 최종 인용 목록을 따로 훑어 각 링크가 ⑴ 실제로 열렸는지 ⑵ 붙은 주장을 실제로 뒷받침하는지 확인한다. 의심스러운 것은 표시하거나 뺀다. **쓰면서 동시에 검증하지 말고 끝난 뒤 별도 패스로** 한다 — 최고 성능 시스템도 인용-주장 대응이 62%다(§7-⑥).
3. `## 정직하게, 아직 모르는 것` — 번호 매김. 각 항목에 **무엇을 하면 확정되는지** 한 줄.
4. `**Sources**` — 링크 목록.

## 중단 조건 (승인 없이 멈춘다)

- **신규 자료 0건이 2루프 연속** → 중단하고 몇 루프까지 갔는지·왜 멈췄는지·남은 질문이 무엇인지 쓴다. 자료 유입이 작동 조건이므로 이건 낭비가 아니라 **작동 불능**이다. 마른 자리를 내부 추론 반복으로 채워 N을 채우지 않는다.
- 앵커 2회 이탈 → 논점이 잘못 잡힌 것이므로 재설정을 제안한다.

## 하지 않는 것

- **실행하지 않는다.** 조사·문안·설계 제안까지다. 파일 수정·커밋·설정 변경은 루프 밖 별도 승인.
- **볼트에 저장하지 않는다**(사용자 확정 2026-08-03). 남길 가치가 있으면 사용자가 그때 지시한다.
- 자료 공백을 매끄러운 추론으로 메우지 않는다. 공백은 공백으로 남긴다.
- 출력에 `lean` §3(도구 나레이션·장식·로그 덤프·패딩) 금지는 그대로. **길이 압축만 적용하지 않는다** — 불확실성·반박·근거는 lean §1 예외다.

## 7. 설계 근거 (2026-08-03 조사)

① **반복 깊이** — 사실확인형(multi-hop QA)은 2스텝이 5스텝 이득의 95%, 3스텝과 5스텝은 통계적 구별 없음([Dissecting Agentic RAG, arXiv 2606.21553](https://arxiv.org/html/2606.21553)). 개방형 조사는 약 9스텝에서 정체([AgentCPM-Report, arXiv 2602.06540](https://arxiv.org/pdf/2602.06540)).

② **반증 지시** — 명시적 반대 지시 55.0% vs baseline 48.3%로 통계적 구별 없음. 역할 배정만 99.2%([Inducing Disagreement, OpenReview mxBmj5LYU2](https://openreview.net/forum?id=mxBmj5LYU2)). ⚠ 다중 에이전트 팀 측정 — **단일 세션 이식은 미확인.** 근거 없는 자기 도전은 오히려 해롭다(FlipFlop: 정확도 −17%, 46% 답 뒤집음, [arXiv 2311.08596](https://arxiv.org/abs/2311.08596)).

③ **drift와 anchoring이 반대로 당김** — 반복 정제는 원 질문에서 벗어난 쿼리를 만든다(완화 = 원 질의 유지). 동시에 초기 자료가 이후를 붙드는 anchoring은 완화 6전략이 **전부 실패**했고 얕은 층에서 작동한다([arXiv 2505.15392](https://arxiv.org/html/2505.15392v2)). 관점 분할이 둘을 동시에 푼다 — CoT가 fixation을, **평범한** 페르소나가 knowledge partitioning을 담당([arXiv 2602.20408](https://arxiv.org/abs/2602.20408)).

④ **Descending** — 초반 광범위 탐색 → 후반 집중이 정적·상승 전략보다 우수(2602.06540). "Start wide, then narrow"([Anthropic multi-agent research system](https://www.anthropic.com/engineering/multi-agent-research-system)). 독립 3자료 수렴.

⑤ **컨텍스트** — 다중턴 평균 39% 하락, 중간 위치 30%+ 하락(lost-in-the-middle), 18개 프론티어 모델 전부 해당. ⚠ **전부 요약·블로그 경유, 원 기술보고서 미확인.** 방향은 여러 출처가 일치하나 크기는 미확정.

⑥ **인용** — 검색 접지 상태에서도 URL 3~13% 날조, deep research 에이전트가 오히려 높음(Gemini DeepResearch 13.3%)([arXiv 2604.03173](https://arxiv.org/html/2604.03173v1)). 인용-주장 대응은 최고 62.20%([ScaffoldAgent, arXiv 2606.20122](https://arxiv.org/html/2606.20122v1)). Anthropic은 쓰기와 인용검증을 별도 에이전트로 분리한다.

⑦ **순차의 역할** — 폭이 증거를 모으고 순차가 구조를 재조직한다. Expansion/Contraction/Revision 셋 다 load-bearing(하나만 빼도 전 지표 하락, 2606.20122). ⚠ 폭이 깊이보다 낫다는 문헌([Search More Think Less, arXiv 2602.22675](https://arxiv.org/html/2602.22675v2))은 사실탐색 과제(BrowseComp) 측정 — **개방형 조사 이식은 미확인.**

**미확인 3건**(②단일세션 이식·⑤수치 크기·⑦과제유형 이식)은 이 스킬의 실전 사용으로 관측한다. 반증이 나오면 해당 항목을 고친다.
