# draft — 초안을 비교 한 장으로

**원칙** = 볼트에 디자인 원칙 노트를 두었으면 초안을 그리기 전에 그것을 먼저 읽는다(제작자 볼트는 D1~D12 · 초안 규칙 · 보이는 방식). 없으면 아래 손 순서와 «하지 말 것»이 최소 규칙이다.

## 1. 먼저 — 초안이 맞는 일인가
- 고를 것이 있으면 초안이다. 아래면 초안 없이 바로 만든다: 원칙·기능 위반 고침 · 이미 고른 안 제작 · 사용자가 자리·모양까지 정해 줌(새 요구가 붙으면 다시 초안) · 양식이 정해진 보고서.
- 초안 없이 간다면 그 까닭을 한 줄 말한다(침묵 생략 금지).

## 2. 손 순서
1. 작업 노트(`0_작업/<영역>/<주제>/작업.md`)에 **할 일 · 합격선**(질문당 누름 수 · 첫 화면 글)을 먼저 적는다. 모양부터 그리지 않는다.
2. `py -3 3_시스템/draft.py new <작업 폴더>/초안/<n>차 [안 수]` → `초안.json` · `A.html`… 뼈대. 지금 화면을 바꾸면 `지금.html` 도 그린다.
3. 안 3개(2~4) · **축이 다르게**(배치 · 표현 · 보이는 때). 모든 안이 **같은 실제 자료 · 같은 폭**(`폭` = 실제 칸: 곁창 320~420 · 창 640~760).
   - 안 하나 = `<style>`(색·글자·간격은 `var(--…)` 만) + `<section data-frame="첫 화면">` + `<section data-frame="누른 뒤 …">`. 누른 뒤·마우스 올림은 칸으로 그린다(`is-hover`).
   - 자료(노트 이름·값·날짜)는 `data-d` · 확인 질문은 `data-ask` · 아이콘은 `<i data-icon="이름"></i>`(옵시디언과 같은 이름 · `draft.py icon <낱말>`로 찾음).
   - brain-base 꼴을 그대로 쓴다: `bb-tp-sec`(묶음) · `bb-tp-row`·`bb-tp-text`·`bb-tp-flair`(줄) · `ib`(아이콘 단추) · `chip`(값·✦ 추천 `is-rec`) · `btn`. 노트 꼴은 `md-view`.
4. `초안.json` 에 안마다 이름(2~4낱말) · 이점 한 줄 · 손해 한 줄(**새 요소 수**를 넣음) · 추천 하나(`"추천": true`) · `까닭` 한 줄.
5. `py -3 3_시스템/draft.py build <폴더>` → `비교.png`·`비교.html` + 검사. **! 는 고친다.** 일부러 어긴 안이면 손해 칸에 적는다. 종료 2 = 검사 걸림.
6. `Read` 로 `비교.png` 를 직접 본다(겹침·잘림·빈 칸). 
7. **보이기** — 늘 같은 꼴:
   - `SendUserFile` `비교.png`(display render).
   - 본문 세 줄: 할 일 · ✦ 추천과 까닭 · «섞어 고를 수 있습니다(예: A① + C②)». 그림을 글로 다시 풀지 않는다.
   - 끝 칸 `wrap_up` 묻는 말 «어느 안으로 하시겠습니까?» · 단추 = 추천 · 차선.
   - 옵시디언 대화창이면 화면 도구 `open <비교.png> right` · 빅보스 하위 세션이면 보스가 보낸다.
8. 고른 뒤: 작업 노트에 고른 안·섞은 칸·사용자 말 그대로 적고 제작. 제작이 끝나고 사용자가 확인하면 `초안/` 은 `fileops.py` 로 휴지통.

## 3. 하지 말 것
- 안을 단추로 바꿔 보는 HTML · 안마다 따로 그림 · 대화에 ASCII 그림 · 글로만 된 안 비교표 — 모두 비교 한 장으로 대신한다.
- 꾸밈으로 차이를 만들지 않는다. 세 안이 색만 다르면 한 안이다.
- 대화 안 위젯·Artifact 로 보이지 않는다(옵시디언 대화창·폰에서 안 됨 · 실제 자료가 밖으로 나감).

예시 = `예시/`(건강 창 고치기 · 지금 + 안 셋 · 실제 자료 11-13) — 처음 쓸 때 `A.html` 을 본보기로 연다.
