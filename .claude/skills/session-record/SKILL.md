# 세션 기록 확정

**시점에 묶이지 않는다.** 이번 세션을 지금 정리해도 되고, 며칠 전 밀린 세션을 뒤늦게 정리해도 된다.

## 0. 대상과 수준을 먼저 정한다

**대상** — 이번 세션인가, `3_시스템/_index/.pending-sessions.txt`에 뜬 밀린 세션인가.

**수준** — **모든 세션에 노트가 필요하지 않다.** 셋 중 하나를 고른다.

| 수준 | 언제 | 무엇을 하나 |
|---|---|---|
| **A 세션노트** | `3_시스템`·`.claude`·`CLAUDE.md`를 건드린 세션 = **결론이 대화에만 남아 사라지는 작업** | 1~5 전부 |
| **B recent 한 줄** | 산출물 노트가 이미 결론 전부인 경우(여행계획·학습노트·계획 수립 등) | 2·3만 |
| **C 생략** | 볼트에 아무것도 안 남긴 질의응답(단발 문제 풀이·단발 조사 등) | 아무것도 안 함 |

근거(빌더 볼트 46세션 실측): 노트를 쓴 31세션의 `3_시스템` 편집 중앙값 7 / 안 쓴 15세션은 0. **볼트 편집이 0인 세션에 노트를 쓴 것은 31건 중 1건뿐.** 산출물 노트가 이미 결론 전부인 세션에 세션노트를 얹으면 중복이다.

**애매하면 한 줄로 묻는다.** 추측으로 A를 고르지 않는다 — 쓸모없는 노트가 볼트를 늘린다.

**사용자가 "넘어가"라고 하면** = 수준 C. `3_시스템/_index/.pending-skip.txt`에 세션 id를 한 줄 추가한다(영구 제외). 파일이 없으면 만든다.

## 1. 세션 요약 노트 (수준 A만)

`2_지식/sessions/YYYY-MM-DD-<주제>.md` — `type:episodic`, 프론트매터는 `3_시스템/conventions.md` 스키마.
담을 것: **발단 · 한 것 · 산출물 · 주요 결정 · 실측 · 검증 · 미결**. 산출물 노트가 따로 있으면 **거기 있는 내용을 복사하지 말고 링크**한다(요약은 원문을 대체하지 않는다).

## 2. `2_지식/recent.md` (수준 A·B)

맨 위에 1줄 추가(35단어/150자 이하) → **10줄 초과분 삭제**.

## 3. `2_지식/open-loops.md` (수준 A·B)

**삭제는 이중 주체** — ①Claude가 이번 세션에서 종결을 확인한 항목 ②사용자가 `- [x]`로 체크한 항목(Claude가 종결을 못 알아챈 것을 사용자가 알려주는 채널). 둘 중 하나면 하위 불릿까지 통째 삭제. **확신 없으면 지우지 말고 보고**(원문이 링크 노트에 남아있는지 확인 후 삭제). 새 미결은 `- [ ]`로 추가. "다음 세션" 기입.

**항목 상한 = 2줄/300자 · 파일 ≤6KB**(T1은 매 세션 전량 주입). 초과하면 이력을 append하지 말고 **gist+링크 1항목으로 교체**(상세는 세션·프로젝트 노트에). 다 쓴 뒤 바이트를 실제로 재서 6KB 이하인지 확인한다.

## 4. incident (해당 시)

이번 세션에 버그 해결이 있었으면 `3_시스템/_ref/`에 incident 노트(`type:incident` + 증상/근본원인/해결/재발방지).

## 5. MOC 등재 — 확인이 아니라 대조·강제

`2_지식/notes/`·`decisions/` 파일명을 `MOC.md`와 대조해 **미등재분을 나열하고 전부 등재**. 프론트매터 없는 노트는 생성 시점에 즉시 보강(지연 금지). 세션로그·incident는 MOC 대상 아님(`_ref`는 weekly-review가 반영), `modules/`는 프론트매터만 요구.

※ Stop 훅(`stop-check.ps1`)이 동일 항목을 결정론 검증해 미처리 시 종료를 차단하지만, 여기서 선제 처리한다.

## 밀린 세션을 뒤늦게 기록할 때

**원본 세션을 다시 열지 않는다** — 커진 세션을 공백 후 재개하면 1회에 수십만 토큰이 통째로 재청구된다. 스텁이 그걸 피하려고 있다.

1. `3_시스템/_index/stubs/<sid>.md`를 읽는다. 무엇을 했는지 뼈대가 있다.
2. **스텁에 '왜'는 없다.** 결론·결정·수치가 필요하면 스텁의 `[L숫자]`가 가리키는 원본 줄만 잘라 읽는다. 통째로 열지 않는다 — 한 줄이 수 MB일 수 있다.
   ```bash
   py -3 -c "import itertools;print(next(itertools.islice(open(P,encoding='utf-8'),N-1,N))[:4000])"
   ```
3. 프론트매터에 `confidence: hypothesized`, 본문 첫 줄에 **"사후 재구성(스텁 기반, 원본 발췌 N곳)"**을 명시한다. 표시하지 않으면 추정이 사실로 굳고 다음 요약이 그것을 근거로 삼는다.
4. 트랜스크립트가 이미 삭제됐으면(보존 기간 경과) **뼈대만 쓰고 그 사실을 적는다.** 없는 '왜'를 지어내지 않는다.
5. 기록을 마치면 `.pending-sessions.txt`는 다음 턴에 자동 갱신된다(직접 지우지 않는다).

## 하지 않는 것

- **커밋** — Stop 훅이 매 턴 한다.
- **`.pending-sessions.txt` 직접 편집** — `session-stub.py`가 매 턴 다시 쓴다. 제외하려면 `.pending-skip.txt`를 쓴다.
- **없는 결론 채우기** — 스텁에 없고 원본에도 없으면 "미상"으로 남긴다.
